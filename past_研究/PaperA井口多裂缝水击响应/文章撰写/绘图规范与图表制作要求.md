# Paper A 论文绘图规范与图表制作标准要求

> **文档性质**：本文档为 *Paper A（多裂缝井筒水击倒谱响应与参数敏感性研究）* 的**统一绘图技术规范与排版生产标准**。
> **目标期刊风格**：严格对标 *SPE Journal / Mechanical Systems and Signal Processing (MSSP) / Nature Portfolio* 等国际顶级期刊标准。
> **生效范围**：Paper A 论文正文所有插图（Figure 5.1 至 Figure 5.7 及引言/方法图件）。

---

## 1. 核心排版与几何比例规范

### 1.1 版面尺寸与子图比例
*   **通栏双栏宽度 (Double-column width)**：总宽度控制在 **$7.0 \sim 7.35\text{ in}$ ($180\text{ mm}$)**，高度控制在 **$2.2 \sim 2.5\text{ in}$**（单排 3 子图结构）；
*   **单栏半栏宽度 (Single-column width)**：总宽度控制在 **$3.5\text{ in}$ ($89\text{ mm}$)**；
*   **子图高宽比 (Subpanel Box Aspect Ratio)**：
    *   所有子图的轴框比例必须严格设定为 **高 : 宽 = 4 : 5**（代码实现：`ax.set_box_aspect(4/5)`）；
    *   确保多子图并排时高度完全一致、网格紧凑且无冗余空白。

### 1.2 四周全封边与刻度规范
*   **全封闭边框 (Full Box Enclosing Spines)**：
    *   开启所有四面边框（`top=True, bottom=True, left=True, right=True`）；
    *   边框线宽统一为 **$0.75\text{ pt}$**（`axes.linewidth = 0.75`），颜色为黑色或极深灰（`#000000` 或 `#2C3E50`）。
*   **刻度线朝向 (Inward Ticks)**：
    *   主刻度线朝向必须**向内**（`xtick.direction = 'in', ytick.direction = 'in'`）；
    *   不开开启上侧，右侧对齐刻度双坐标时开启（`xtick.top = True, ytick.right = True`）；
    *   主刻度长度为 **$3.0\text{ pt}$**，线宽 **$0.75\text{ pt}$**。

## 2. 字体与文字排版规范

### 2.1 字体家族
*   **西文与正文字体**：统一强制采用 **Times New Roman**（备用回退字体：`Times, DejaVu Serif, serif`）；
*   **数学公式与特殊符号**：采用与 Times 完美契合的 **STIX 数学字体集**（代码实现：`mpl.rcParams['mathtext.fontset'] = 'stix'`）；
*   **禁止项**：严禁在最终投稿图中混用 Arial、Calibri 或 SimHei 等无衬线/非标准中文字体。

### 2.2 字号层级标准
| 元素类型 | 标准字号 (pt) | 样式 (Style) | 格式说明 |
| :--- | :--- | :--- | :--- |
| **子图序号** | **9.5 pt** | **加粗 (Bold)** | 必须使用带小括号格式：**(a)**, **(b)**, **(c)**，置于子图左上方（`loc='left', pad=5`） |
| **坐标轴标题 (Axis Labels)** | **8.0 pt** | 常规 (Regular) | 物理量名称 + 符号 + 括号单位，如 `Fracture Spacing $S$ (m)` |
| **坐标轴刻度 (Tick Labels)** | **7.0 pt** | 常规 (Regular) | 紧贴刻度线，数值间距均匀 |
| **图例文本 (Legend Text)** | **6.5 ~ 7.0 pt** | 常规 (Regular) | 无外框（`frameon=False`），控制 handlelength 为 1.0 ~ 1.2 |
| **色条标注 (Colorbar Label)** | **6.8 ~ 7.0 pt** | 常规 (Regular) | 紧贴色阶条侧边，字号与刻度匹配 |

### 3.2 连续色阶与热力图规范 (Colorbars)
*   **色阶放置位置**：**必须置于子图右侧垂直排列**（Vertical Colorbar），严禁底部横放破坏水平对齐；
*   **色阶宽度与间距**：`fraction=0.046, pad=0.04`，刻度字号 $6.0\text{ pt}$，刻度线长 $2.0\text{ pt}$；
*   **色彩映射 (Colormap)**：2D 响应相图推荐采用平滑冷暖渐变色阶（如定制 `nature_blue_warm`：浅蓝 `#EBF5FB` $\rightarrow$ 湛蓝 `#5DADE2` $\rightarrow$ 橙黄 `#F5B041` $\rightarrow$ 暖红 `#E74C3C`）。

## 4. 数据可读性与防遮挡硬性规则（Zero-Collision Policy）

> [!IMPORTANT]
> **图例防穿插硬性红线**：图例文本及标示图标**严禁与任何数据曲线、散点标记、谱峰或误差棒发生重叠穿插**。

### 4.1 落地执行措施
1. **动态 Y 轴裕度扩展 (Headroom Expansion)**：
   * 在绘制曲线图（如 $P_i$ 随间距演化）时，若数据峰值达到 $3.2$，**必须将 Y 轴上限扩展至 $4.5 \sim 4.8$**，为左上角或右上角的图例留出至少 $30\%$ 的纯白空白区；
   * 在绘制归一化相对比值（$\alpha_i \in [0, 1.0]$）时，**必须将 Y 轴上限扩展至 $1.30 \sim 1.35$**，确保图例完全悬浮于基准线 $1.0$ 之上的留白区。
2. **图例位置自适应优化**：
   * 数据在右侧低平 $\rightarrow$ 图例设在 `upper right`；
   * 数据在左侧低平 $\rightarrow$ 图例设在 `upper left`；
   * 若全域充满数据，必须将图例提取至多子图顶部通栏放置，或置于专属的图例子面板中。
3. **网格线与参考线分层**：
   * 参考线（如真实裂缝位置虚线、$\alpha=1.0$ 点线）图层必须置于底层（`zorder=0`），线宽不超过 $0.6\text{ pt}$，透明度 $\alpha \le 0.7$。

## 5. 文件输出与交付技术格式

每次绘图脚本执行必须同步输出以下三种格式到 `文章撰写/稿件/图表数据/` 目录：

1. **矢量源文件 (SVG)**：
   * `svg.fonttype = 'none'`，保留文字为可编辑文本对象，方便 Illustrator / Inkscape 进行微调与拼版；
2. **出版级矢量文件 (PDF)**：
   * `pdf.fonttype = 42`，完全嵌入 TrueType 字体，符合 Elsevier / SPE / IEEE 提交系统的免预检要求；
3. **高分辨率光栅预览图 (PNG)**：
   * 分辨率设定为 **$\ge 400\text{ DPI}$**，采用紧凑剪裁（`bbox_inches='tight'`），用于文档内嵌展示与快速评审。

## 6. 标准 Python 绘图初始化模板代码

在编写 `Figure_5_X.py` 脚本时，必须包含以下标准初始化与配置块：

```python
import os
import sys
import numpy as np
import pandas as pd
import matplotlib as mpl
import matplotlib.pyplot as plt

# 1. 统一字体与排版参数配置
mpl.rcParams.update({
    # 字体与公式：Times New Roman + STIX
    "font.family": "serif",
    "font.serif": ["Times New Roman", "Times", "DejaVu Serif", "serif"],
    "mathtext.fontset": "stix",
    "svg.fonttype": "none",
    "pdf.fonttype": 42,
    
    # 字号层级
    "font.size": 7.5,
    "axes.labelsize": 8.0,
    "axes.titlesize": 8.5,
    "xtick.labelsize": 7.0,
    "ytick.labelsize": 7.0,
    "legend.fontsize": 7.0,
    
    # 封闭边框与内向刻度
    "axes.linewidth": 0.75,
    "axes.spines.top": True,
    "axes.spines.right": True,
    "axes.spines.left": True,
    "axes.spines.bottom": True,
    "xtick.direction": "in",
    "ytick.direction": "in",
    "xtick.top": True,
    "ytick.right": True,
    "xtick.major.size": 3.0,
    "ytick.major.size": 3.0,
    "xtick.major.width": 0.75,
    "ytick.major.width": 0.75,
    
    # 线宽与图例
    "lines.linewidth": 1.1,
    "lines.markersize": 3.8,
    "legend.frameon": False,
    "figure.dpi": 300,
})

# 2. 统一子图生成与高宽比锁定模板 (以 1x3 组合图为例)
def create_standard_1x3_figure():
    fig, axes = plt.subplots(1, 3, figsize=(7.20, 2.35), constrained_layout=True)
    labels = ["(a)", "(b)", "(c)"]
    for ax, lab in zip(axes, labels):
        ax.set_box_aspect(4/5)  # 严格锁定 4:5 高宽比
        ax.set_title(lab, loc="left", fontsize=9.5, fontweight="bold", pad=5)
    return fig, axes

# 3. 统一保存函数
def save_nature_figure(fig, filepath_without_ext):
    fig.savefig(f"{filepath_without_ext}.png", dpi=400)
    fig.savefig(f"{filepath_without_ext}.svg", bbox_inches="tight")
    fig.savefig(f"{filepath_without_ext}.pdf", bbox_inches="tight")
    plt.close(fig)
```

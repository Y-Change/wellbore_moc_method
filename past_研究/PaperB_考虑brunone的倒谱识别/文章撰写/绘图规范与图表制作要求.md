## 1. 核心排版与几何比例规范

### 1.1 版面尺寸与子图比例
*   **通栏双栏宽度 (Double-column width)**：总宽度控制在 **$7.0 \sim 7.35\text{ in}$ ($180\text{ mm}$)**，高度控制在 **$2.2 \sim 2.6\text{ in}$**（单排 3 子图结构）；
*   **单栏半栏宽度 (Single-column width)**：总宽度控制在 **$3.5\text{ in}$ ($89\text{ mm}$)**；
*   **子图高宽比 (Subpanel Box Aspect Ratio)**：
    *   所有二维曲线子图的轴框比例统一设定为 **高 : 宽 = 4 : 5**（代码实现：`ax.set_box_aspect(4/5)`）；
    *   热力图/时频图子图根据数据维度精确对齐，并保持色条高度与主图一致。

### 1.2 四周全封边与刻度规范
*   **全封闭边框 (Full Box Enclosing Spines)**：
    *   开启所有四面边框（`top=True, bottom=True, left=True, right=True`）；
    *   边框线宽统一为 **$0.75\text{ pt}$**（`axes.linewidth = 0.75`），颜色为黑色（`#000000`）。
*   **刻度线朝向 (Inward Ticks)**：
    *   主刻度线朝向必须**向内**（`xtick.direction = 'in', ytick.direction = 'in'`）；
    *   开启上侧与右侧对齐刻度（`xtick.top = True, ytick.right = True`）；
    *   主刻度长度为 **$3.0\text{ pt}$**，次刻度为 **$1.5\text{ pt}$**，线宽 **$0.75\text{ pt}$**。

## 2. 字体与文字排版规范

### 2.1 字体家族
*   **西文与正文字体**：统一强制采用 **Times New Roman**（备用回退字体：`Times, DejaVu Serif, serif`）；
*   **数学公式与特殊符号**：采用与 Times 完美契合的 **STIX 数学字体集**（代码实现：`mpl.rcParams['mathtext.fontset'] = 'stix'`）；
*   **禁止项**：严禁在最终投稿图中混用 Arial、Calibri 或 SimHei 等无衬线/非标准中文字体。

### 2.2 字号层级标准
| 元素类型 | 标准字号 (pt) | 样式 (Style) | 格式说明 |
| :--- | :--- | :--- | :--- |
| **子图序号** | **9.5 pt** | **加粗 (Bold)** | 必须使用带小括号格式：**(a)**, **(b)**, **(c)**，置于子图左上方（`loc='left', pad=5`） |
| **坐标轴标题 (Axis Labels)** | **8.0 pt** | 常规 (Regular) | 物理量名称 + 符号 + 括号单位，如 `Time $t$ (s)`, `Quefrency $\tau$ (s)` |
| **坐标轴刻度 (Tick Labels)** | **7.0 pt** | 常规 (Regular) | 紧贴刻度线，数值间距均匀 |
| **图例文本 (Legend Text)** | **6.5 ~ 7.0 pt** | 常规 (Regular) | 无外框（`frameon=False`），控制 handlelength 为 1.0 ~ 1.2 |
| **色条标注 (Colorbar Label)** | **6.8 ~ 7.0 pt** | 常规 (Regular) | 紧贴色阶条侧边，字号与刻度匹配 |

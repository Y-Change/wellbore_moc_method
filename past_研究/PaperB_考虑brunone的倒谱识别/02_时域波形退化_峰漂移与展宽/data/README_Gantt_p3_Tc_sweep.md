## 2. 三句话核心定论 (审定定稿版)

1. **倒谱时钟的系统性偏深随关井时间 $T_c$ 延长呈单调缩小趋势**：相对稳态漂移量由阶跃关井下的 $\delta x = \mathbf{+9.43\,\mathrm{m}}$，单调降至 $50\,\mathrm{ms}$ 下的 $\mathbf{+7.25\,\mathrm{m}}$、$200\,\mathrm{ms}$ 下的 $\mathbf{+5.80\,\mathrm{m}}$ 及 $1000\,\mathrm{ms}$ 下的 $\mathbf{+5.08\,\mathrm{m}}$；在现场典型关井时间下偏深幅度收敛但**未完全消失**，稳定保持在 $\mathbf{5 \sim 7\,\mathrm{m}}$。
2. **峰值时钟在有限关井下表现为“先降后升”非单调响应**：相对稳态漂移量在 $T_c = 50 \sim 200\,\mathrm{ms}$ 时由 $+9.43\,\mathrm{m}$ 缩小至 $\delta x = \mathbf{+5.08\,\mathrm{m}}$，但在 $T_c = 1000\,\mathrm{ms}$ 时由于大斜坡波包平缓展宽，极大值后移回升至 $\delta x = \mathbf{+7.25\,\mathrm{m}}$（绝对误差 $\Delta x = +7.13\,\mathrm{m}$）。
3. **物理 onset 时钟在现场快关井（$T_c \le 200\,\mathrm{ms}$）下保持米级精度**：在阶跃至 $200\,\mathrm{ms}$ 关井区间内，首波前起跳点未受前向背景波干扰，绝对误差牢固控制在 $|\Delta x| \le \mathbf{0.85\,\mathrm{m}}$（$T_c=200\,\mathrm{ms}$ 时 $|\Delta x| = 0.13\,\mathrm{m}$），完全印证了首波前走时在有限关井下的声速传播不变性。

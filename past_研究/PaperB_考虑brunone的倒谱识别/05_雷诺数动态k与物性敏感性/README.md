# 05 非稳态摩阻参数敏感性与阻尼混淆分析模块

## 模块定位
本模块系统剖析物理参数（井筒非稳态摩阻 $k$ 与地层裂缝滤失系数 $k_{\text{leak}}$）对井口水锤宏观阻尼及倒谱特性的控制规律，检验科学假说 H2（井筒摩阻与缝网复杂度阻尼混淆假说）。

## 目录结构
- `./code/`:
  * `run_k_kleak_surface.py`: 16 点 $(k \times k_{\text{leak}})$ 正交正演、CWT 阻尼比提取与响应面绘图脚本；
  * `probe_realised_k.py`: 局部雷诺数与实际生效 $k$ 探针分析脚本。
- `./data/`:
  * `k_kleak_damping_surface.csv`: 16 点正交阻尼比与倒谱漂移数据全表；
  * `README_Gantt_p4_k_kleak_confusion.md`: Gantt p4 阻尼混淆实验审定定论笔记（审定定稿版）。
- `./figures/`:
  * `fig_k_kleak_damping_surface.png`: 诊断用响应面与等高线图件（(a) CWT 阻尼比 $\zeta(k, k_{\text{leak}})$；(b) 倒谱漂移 $\delta x_{\text{cep}}(k, k_{\text{leak}})$）；
  * `fig_k_kleak_damping_surface.svg`: 矢量图件。

## 核心审定数据与 H2 分层定论
1. **科学假说 H2 分层判决**：
   - **全网格边界**（含趋势上沿 $k=0.05$ 与高滤失 $5\times 10^{-4}$）：井筒摩阻增量 $\Delta\zeta(k) = \mathbf{+0.02186}$（$+55.0\%$）与裂缝滤失增量 $\Delta\zeta(k_{\text{leak}}) = \mathbf{+0.01846}$（$+48.7\%$）端点效应处于同等量级；“低滤失 + 强 UF”（$\zeta = 0.0606$）超过“高滤失 + 稳态摩阻”（$\zeta = 0.0564$），**假说 H2 在全网格边界上成立**；
   - **主文弱阻尼档**（$k=0.01$ 与 $0.02$）：UF 对阻尼比的增量仅为 $+0.00277$（$+7.0\%$）与 $+0.00648$（$+16.3\%$），宏观包络衰减仍主要由高滤失档主导；**弱 $k$ 档不夸大为同等混淆**。
2. **倒谱时钟偏移与地层滤失解耦**：
   - 在弱阻尼 $k \le 0.02$ 区间内，倒谱相对稳态偏深 $\delta x_{\text{cep}}$ 严格锁定（$k=0.01$ 锁定为 $+9.43\,\mathrm{m}$）；在 $k=0.05$ 上沿仅差 1 个采样点（$35.52$ vs $36.25\,\mathrm{m}$）；
   - 证实倒谱测距偏深纯属井筒介质能量重心滞后，基本不受地层滤失强弱干扰。
3. **方法论边界说明**：
   - 提取基频 $f_0 = 3/49\,\mathrm{Hz}$ 为 FFT 栅格频率，$\zeta$ 仅作正交面相对灵敏度比较；
   - 拟合窗 $[2, 45]\,\mathrm{s}$ 的 $R^2 \in [0.77, 0.85]$ 说明多谐波干涉存在，不将 $\zeta$ 包装为精密绝对模态阻尼。

# T01 倒谱作为估计器（已结：不是信息墙）

## 核心问题

近距倒谱失败，是数据里没有信息，还是倒谱没用上全波形？

> Paper C 已结：[[PaperC_MOC主路径结案]]。思考用下面锁定表，不要用倒谱旁瓣宽度当分辨率。

## 锁定结论（用这些数想问题）

| 结论 | 关键数 | 证据 |
|---|---|---|
| 无信息论近距墙 | CRB 与间距几乎无关；σ_x≈0.025 m @40 dB, fc=20 Hz | [[EXP-20260806-002]] / [[EXP-20260806-003]] |
| MLE 可达界 | RMSE/CRB ≈ 0.96–1.39；n≤5 仍 ≈0.86–1.18 | EXP-003, [[EXP-20260807-001]] |
| 倒谱是低效估计器 | SNR=∞ 仍 ~12 m；有噪 100–400 m；盲 F1@10=0.238 | EXP-003, [[EXP-20260802-001]] |
| 实用墙 = 模型误差 | brunone↔steady ~30 m；波速 −1% 非线性 ~120 m | EXP-003, [[EXP-20260807-003]] |
| 配对剪刀差 | 倒谱 0.23→0.64；P0/PN 下降 | [[EXP-20260807-002]] |
| 缝数 ≠ 位置 CRB | BIC exact-count=1.0（oracle）；PN 盲计数 30.5% | EXP-20260807-001 |
| 临界 δa/a | ≈2×10⁻⁵（偏差落到噪声界） | EXP-002 |

假说：信息受限 / 优化多峰 → **否证**。合成基准 = **估计器低效**；失配/现场 = **偏差受限**。

处方：定位用 MOC 全波形 MLE；倒谱只当初值。

## 不要再当墙的数

历史上把倒谱谱支撑写成 \(\Delta d_{\mathrm{DR}}=a/(2B_{\mathrm{coh}})\)，DR=80 dB 时得到约 38 m。那是**该变换的旁瓣宽**，随 DR 从约 220 m 变到 4 m，不是物理极限，也不是盲检测下限。5 m 双缝在盲协议下可以分开。详见 [[EXP-20260730-025]]、[[EXP-20260801-001]]。

工作讨论、Paper A/B、新实验**不要再引用 38.36 m 当目标或上限**。

## 边界

- 历史倒谱匹配用真值控峰距/缝数，**非盲**；旧 JSON 勿引用（[[EXP-20260801-001]]）。
- `match_tolerance_m=10 m` 小于形式失配 ~30 m，F1@10 解释受限。
- 趾端 depth≈L 有固定伪峰，需要搜索窗。

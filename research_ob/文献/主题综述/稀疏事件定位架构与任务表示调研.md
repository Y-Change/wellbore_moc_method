# 稀疏事件定位：任务表示与架构优先级调研

> **数据来源**：ARIS deep-research、research-lit 检索与对抗核验（2026-07-30）  
> **触发证据**：DCCDM overfit16 失败（epsilon loss↓99.55%，生成仍失败）→ [[EXP-20260729-001-DCCDM-overfit16稀疏生成失败]]  
> **已落地跟进**：P0-A 直接监督基线 → [[EXP-20260730-001-P0A原始波形直接裂缝定位]]、主题 [[T07-DCCDM代理模型]]  
> **证据边界**：下列排序是「证据距离 × 失败原因 × 实现成本 × 可诊断性 × 代码复用」的工程研究建议，**不是**水击领域已发表的直接性能排名。无文献证明任一方案在本项目停泵数据上必然最优。

---

## 0. 核心判断

**当前最优先的不是继续修补 DDPM，而是先修正任务表示，并建立直接监督的稀疏事件定位上限。扩散模型降为后续对照分支。**

推荐路线（摘要）：

1. 重新设计标签与输出空间，避免宽 Gaussian 把近邻裂缝主动合并。
2. 建立 PhaseNet 式 1D U-Net 稠密事件检测基线（P0）。
3. 并行建立 LISTA/FISTA 深度展开稀疏反卷积基线（P0）。
4. 长序列再比较 ActionFormer 式局部注意力金字塔与 TadTR/DETR 式集合预测（P1/P2）。
5. 物理先验按 F0→F1→F2→F3 消融：固定输入通道 → 独立物理编码器 → 再考虑可微前端。
6. 仅当直接监督能可靠过拟合并泛化后，再修条件扩散（zero-terminal-SNR、last timestep、v-prediction、Min-SNR、事件感知辅助损失）。

## 1. 任务定义中的信息压缩（优先于架构）

### 1.1 时间 / 深度格点

| 量 | 取值 |
|---|---|
| \(t_f\) | 30 s |
| \(N\) | 4096 |
| \(\Delta t\) | \(30/4095 \approx 7.326\) ms |
| \(\Delta x = a\Delta t/2\)（\(a=1450\)） | ≈ 5.31 m |

缝距相对格点：5 m ≈ 1 格；10 m ≈ 2；20 m ≈ 4；50 m ≈ 9.4。

### 1.2 宽 Gaussian 标签的结构性矛盾

旧设定 `sigma_impulse_s = 0.15 s` → \(\sigma_x = 1450\times0.15/2 = 108.75\) m ≈ **20.5 个输出格点**。

| 裂缝间距 | 相对当前 \(\sigma\) |
|---|---|
| 5 m | 0.046σ |
| 10 m | 0.092σ |
| 20 m | 0.184σ |
| 50 m | 0.460σ |
| 100 m | 0.920σ |

**观察**：训练前多数近邻裂缝已被合并成宽峰。  
**解释**：要求独立多峰，却用 \(\sigma\approx108.75\) m 的真值合并峰 → U-Net / Transformer / diffusion 都无法从已合并监督中稳定学习独立裂缝数。

### 1.3 推荐标签 / 输出方案

| 方案 | 要点 | 用途 |
|---|---|---|
| **A 窄 Gaussian 热图** | \(\sigma=1\)–2 格（≈0.007–0.015 s，约 5–11 m）；若物理可分辨≈38 m，则 \(D<38\) m 标为不可分辨组，或只在 \(D\ge40\)–50 m 评逐缝 | PhaseNet 式稠密检测 |
| **B 分类 + 亚格点偏移** | 每格：event prob、sub-bin offset、Cf | 缓解 5.31 m/grid 量化 |
| **C 集合预测** | \(K\) 个 query → \(p_{\mathrm{exist}}, x, C_f,\)（可选 \(k_{\mathrm{leak}},\sigma_x\)）；Hungarian 匹配 | 可变缝数、连续深度、避免峰重叠 |

**注意**：输出网格分辨率 ≠ 定位精度。倒谱谱支撑宽度**不是**物理上限；位置 CRB 为厘米级，倒谱离界是估计器问题（见 [[T01-倒谱分辨率极限]]）。本调研写于 PhaseNet 之前，路线排序已过时，勿当执行清单。

## 2. P0 主基线：PhaseNet 式 1D U-Net

**文献**：Zhu & Beroza, 2019, PhaseNet — 连续波形 → 对齐时间轴的 P/S/noise 概率；1D U-Net + 软 Gaussian 到时 + 局部峰值；可变事件数。

**与本任务的距离**：长 1D 物理波形、极稀疏到达、可变事件数、需较精确时位、背景占绝大多数 — 成熟先例中最近。

**最小架构建议**：

```
Input: H_wh_norm [B,1,4096]
       optional dH/dt, cepstrum → arrival axis
  → 1D U-Net (32→64→128→256)
  → Event head (sigmoid) + Amplitude head (softplus)
```

**损失（工程推断，非 PhaseNet 原文）**：

\[
L = L_{\mathrm{event}} + \lambda_{\mathrm{amp}} L_{\mathrm{amp}} + \lambda_{\mathrm{count}} L_{\mathrm{count}}
\]

- event：weighted BCE / focal  
- amp：仅真峰邻域 Smooth L1  
- count：\(\int p_{\mathrm{event}}\) vs 真实缝数  

**优先级：P0 必须先实现。** 优点：易训易诊、无百步逆扩散、峰位 F1 可 early stop。缺点：近事件仍受网格与带宽限制；需阈值与最小峰距。

---

## 3. P0 物理稀疏基线：LISTA / FISTA 深度展开

**问题形式**：\(y = Hr + n\)，\(\min_r \tfrac12\|y-Hr\|_2^2 + \lambda\|r\|_1\)。

**文献基础（高）**：Gregor & LeCun 2010 LISTA；Daubechies et al. 2004；Beck & Teboulle 2009 FISTA；Monga et al. 2021 Algorithm Unrolling；Borgerding et al. 2017 AMP 网络。  
**水击直接证据：缺失**；对本项目适用性属强物理推断。

**与仓库关系**：已有 `analysis/sparse_deconv/`（FISTA、盲稀疏、BIC/L-curve）→ 可展开 8–16 层。

| 版本 | 内容 |
|---|---|
| 固定物理核 LISTA | \(h\) 来自单缝 MOC/参考；只学 \(\eta_k,\theta_k\) |
| 半盲展开 | \(h = h_{\mathrm{physics}}+\Delta h\)；约束能量、带宽、因果、相位/频散 |

**优先级：P0，与 PhaseNet U-Net 并行。** 关联主题 [[T05-稀疏反卷积]]。

---

## 4. P1 长序列：ActionFormer 式局部注意力金字塔

**文献**：ActionFormer (arXiv:2202.07925, ECCV)；多尺度时间金字塔 + 局部窗口 self-attention；每位置输出类别与时间边界。

**迁移**：裂缝是点事件 → 将边界头改为 center offset / width-uncertainty / amplitude。金字塔例：4096→2048→1024→512。

**优先级：P1**（U-Net 成功后再跑）。证据来自视频定位，非水击。

---

## 5. P1/P2 可变缝数：TadTR / DETR 集合预测

**文献**：DETR；TadTR (arXiv:2009.03578, ICCV 2021)。固定 \(K\) queries + Hungarian；未匹配 → no-object。

**建议**：最大缝数 6 → \(K=8\)–10；每 query：\(p_{\mathrm{exist}}, x_{\mathrm{norm}}, \log C_f,\)（可选 \(\log k_{\mathrm{leak}}, \sigma_x\)）。

**优先级：P1/P2** — 当 Gaussian 标签被证明是主瓶颈时重点比较。需防 query collapse 与 no-event 失衡。

---

## 6. TCN：低成本对照，非主创新

**文献**：Bai, Kolter & Koltun 2018；Lea et al. 2017。  
本轮**未**找到充分核验证据证明「纯 TCN 在多裂缝水击稀疏定位优于 U-Net」。

定位：低成本长感受野 backbone（dilation 1,2,4,…,128）→ event + amp heads。  
**优先级：P1 架构对照。**

---

## 7. 物理信号与 AI 融合（四级消融）

最强可迁移先例：**DDSP**（Engel et al. 2020）— 经典信号处理可作可微模块嵌入网络；**不能**证明可微前端一定优于固定通道，或倒谱必须放进 cross-attention。

| 级      | 内容                                                          | 目的                                                 |
| ------ | ----------------------------------------------------------- | -------------------------------------------------- |
| **F0** | 仅归一化 \(H_{\mathrm{wh}}\)                                    | 原始观测上限                                             |
| **F1** | 固定多通道：\(H\)、\(dH/dt\)、倒谱映到到达轴、可选 STFT/包络                    | 倒谱是否真增益；**必须**做 \(t_{\mathrm{target}}=t_s+q\) 坐标变换 |
| **F2** | 双编码器 + FiLM / gated addition / 局部 cross-attn（优先 gated/FiLM） | 每尺度融合，避免每层全局 2048 倒谱 attention                     |
| **F3** | 受约束可微解频散 \(G(f;\theta)\) 或物理核 + 残差；限制增益、平滑、非负、identity init | 真物理前端 vs 现有学习型 CNN                                 |

**顺序**：F0 → F1 → F2 → F3。不建议一开始联合训练所有模块。关联 [[T06-频散补偿后向传播]]。

## 8. 扩散修复（仅 P0 通过后）

### 已验证直接问题

100-step 线性 schedule：\(\bar\alpha_T=0.3636\)，\(\sqrt{\bar\alpha_T}\approx0.603\) → 训练终点仍保留约 60% 信号，推理从纯噪声开始 → train/sample mismatch。

**文献**：Lin et al., Common Diffusion Noise Schedules and Sample Steps are Flawed (WACV 2024) — zero-terminal-SNR；从最后训练步推理；v-prediction；CFG 时 guidance rescale（本模型无 CFG 则暂无关）。

| ID | 修复 |
|---|---|
| D0 | 当前 linear-100 + ε |
| D1 | cosine / zero-terminal-SNR + ε |
| D2 | zero-SNR + last timestep + ε |
| D3 | D2 + v-prediction |
| D4 | D3 + Min-SNR（Hang et al. 2023 ICCV） |
| D5 | D4 + 事件感知 \(x_0\) 辅助损失（工程推断） |

**建议 gate**：\(\bar\alpha_T < 10^{-4}\)；并查 raw MAE vs zero baseline、peak F1、峰数误差、背景均值。

**EDM 诊断顺序**（Karras et al. 2022）：端点一致性 → prediction 参数化 → timestep 加权 → preconditioning → sampler。不要一次重写全部 DDPM。

**Min-SNR 边界**：只缓解不同噪声步梯度冲突，**不**解决 4096 点中背景占绝大多数的问题。

## 9. 推荐下一版主架构名义

暂不主推「DCCDM」，先建 **PI-PhaseNet-1D**：

```
Raw H_wh → per-trace norm
  ├─ Raw encoder (Conv/TCN)
  └─ Physics encoder (cepstrum/STFT)  [消融后再开]
        → gated fusion → 1D U-Net decoder
        → event_probability [B,1,N_depth]
        → Cf_amplitude      [B,1,N_depth]
```

可选：输入 30 s×4096 与输出深度网格解耦（如 3500–4800 m × 1024 → \(\Delta x\approx1.27\) m），仍受 ~38 m 物理分辨约束。

## 10. 优先实验矩阵

### 阶段 P0：数据是否可反演

| ID | 模型 | 输入 | 输出 | 目的 |
|---|---|---|---|---|
| P0-1 | 1D U-Net | raw H | 窄事件图 | 直接检测上限 |
| P0-2 | 1D U-Net | raw + cepstrum | event + Cf | 倒谱增益 |
| P0-3 | LISTA/FISTA 展开 | raw/dedispersed | 稀疏反射率 | 物理稀疏基线 |
| P0-4 | zero baseline | — | all zero | 防背景 MSE 误导 |

**建议通过标准**：overfit16 fixed F1 ≥ 0.90；strict F1 ≥ 0.75；raw map 优于 zero；峰数误差≈0。  
（落地实验见 [[EXP-20260730-001-P0A原始波形直接裂缝定位]]，gate 合同以仓库 `event-primary-v3` 为准。）

### 阶段 P1：物理融合（固定最优直接模型）

F0 raw → F1 +cepstrum → F2 +dH/dt → F3 dual encoder gated → F4 constrained de-dispersion。控制参数量、split、seed、epoch、峰阈值、容差。

### 阶段 P2：事件表示

R0 窄 Gaussian；R1 heatmap+offset；R2 TadTR set；R3 LISTA reflectivity。重点：1–6 缝、近邻、D=20/50/100、强弱 Cf、深部弱缝。

### 阶段 P3：长序列模型

L0 U-Net；L1 dilated TCN；L2 ActionFormer 式；L3 TadTR。

### 阶段 P4：修复 diffusion

仅 P0 可靠后：D0–D5（见 §8）。最终对照：直接 U-Net、LISTA、ActionFormer、TadTR、修复后 diffusion。

## 11. 暂不优先

1. **仅靠加 DDPM epoch**：已证 loss 大降、生成仍失败 → 非简单欠训练。  
2. **仅靠抬高 soft-threshold**：裁掉错误分布 ≠ 学会背景。  
3. **同时堆倒谱+STFT+小波+解频散+多辅助损失**：无法归因。  
4. **声称 TCN / 点过程 / 展开网络已在水击任务验证**：本轮无足够直接证据；属「算法成熟、适合迁移、待本项目验证」。

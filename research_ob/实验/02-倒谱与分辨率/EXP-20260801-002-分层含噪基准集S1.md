# EXP-20260801-002 分层含噪基准集（EXP-011 阶段 S1）

## 基本信息

- 实验编号：EXP-20260801-002
- 日期：2026-08-01
- 状态：completed
- 研究主题：[[T01-倒谱分辨率极限]]（服务 Paper B / T07 诊断）
- 论文项目：Paper B
- 上游：[[EXP-20260801-001-盲检测协议落地与历史结果复算]]、
  [[EXP-20260730-011-超分辨定位框架重构与模块化架构路线]] 阶段 S1、
  [[EXP-20260730-021-T01无真值盲分辨率与噪声DR矩阵]]（本集为其输入）

## 1. 实验目的

生成按**固定间距格子分层**、并带 **SNR 后处理轴**的基准数据集，补齐
`lhs_dataset_2000`（5–20 m）与 `lhs_dataset_6000`（≥50 m）之间的 20–50 m 空白，
作为 EXP-021 / S2 盲分辨率矩阵的统一输入。

## 2. 研究假设

- H1：固定间距分层比连续 LHS 更适合画 F1-vs-间距曲线。
- H2：噪声后处理（不进 MOC）可使同一清洁波形复用于全部 SNR，且可复现。

本实验只交付数据与 manifest，不检验检测性能。

## 3. 实验配置

| 参数 | 数值 | 说明 |
|---|---:|---|
| 间距格子 [m] | 5, 8, 12, 20, 30, 38, 50, 80, 120 | 含 20–50 m；38 m 对齐 DR=80 谱支撑 |
| SNR [dB] | inf, 40, 30, 20, 10 | 后处理 AWGN；inf = 清洁 |
| 每格清洁样本 | 30 | ≥ EXP-021 预注册下限 |
| 缝数 | 2 | 排除缝数混杂 |
| 摩阻 / tf / dt | brunone / 30 s / 1 ms | 约 4 次往返 |
| 种子 | 20260801 | 参数采样 + 噪声种子基 |
| 噪声定义 | 停泵后 `H_wh` 方差作信号功率 | `10·log10(P_s/P_n)` |

顺带修正：`lhs_config.md` 旧写「最小间距 ≥15 m」，与代码 `min_spacing=5` /
`max_spacing=20` 不一致，已改为与代码一致，并新增分层基准集专节。

## 4. 代码与命令

- 配置：`moc_simulate/lhs_config.py::BENCH_STRATIFIED_CONFIG`
- 核心：`moc_simulate/stratified_bench.py`（采样 / AWGN / manifest）
- 入口：`moc_simulate/run_stratified_bench.py`
- 测试：`tests/test_stratified_bench.py`（5 条）
- Smoke：
  ```
  python moc_simulate/run_stratified_bench.py --smoke --materialize-noise
  ```
- 生产：
  ```
  python moc_simulate/run_stratified_bench.py --n-per-spacing 30 --workers 14 --tf 30 --friction brunone --out-dir output/bench_stratified
  ```

噪声默认**不落盘**：`manifest.csv` 含 `noise_seed`，加载时用
`apply_awgn(H_wh, snr_db, noise_seed)` 即时生成。需要落盘时加 `--materialize-noise`。

## 5. 数据与输出

- Smoke：`output/bench_stratified_smoke/`（18 clean × 5 SNR；含 `data_noisy/`）
- 生产：`output/bench_stratified/`
  - `data_clean/case_XXXXX.npz` × 270
  - `clean_summary.csv`
  - `manifest.csv`（1350 行 = 270 × 5 SNR）
  - `bench_metadata.json` / `cell_counts.json`

单个 npz 键：`t, H_wh, Q_wh, x_f, Cf, kleak, n_frac, spacing_m, friction, tf, snr_db`
（清洁样本 `snr_db=inf`）。

## 6. 结果

### 定量结果

| 指标 | Smoke | 生产 |
|---|---:|---:|
| 清洁 PASS/FAIL | 18/0 | **270/0** |
| manifest 行数 | 90 | **1350** |
| 每 (spacing,SNR) 格样本数 | 2 | **30（min=max）** |
| 仿真耗时 | 0.26 min | 6.56 min |

单元测试：`tests/test_stratified_bench.py` 5/5 通过；与协议测试合计 12/12。

### 定性现象

- 9 个间距格子均满员；20/30/38 m 空白已补上。
- 噪声种子 `base + case_id×1000 + snr_tag`，同 (case, snr) 可复现。

## 7. 分析与解释

- H1/H2 在数据工程层面成立：格子完整、噪声后处理可复现。
- 本集**不回答**盲分辨率数值；那是 S2 / EXP-021 的任务。
- 混杂因素：默认双缝、brunone、tf=30 s；若后续要多缝/steady 对照，应另开子集或加轴，勿静默混入。

## 8. 异常与失败

- 生产跑 stdout 在 Windows 上缓冲严重，进度条长时间不可见；以 `data_clean` 文件数与最终 exit code 为准。无 FAIL。

## 9. 结论

> 一句话结论：`output/bench_stratified/` 已交付——9 间距 × 5 SNR × 30 样本，
> 清洁 270/270 PASS，manifest 1350 行，可直接供 S2 / EXP-021 使用。

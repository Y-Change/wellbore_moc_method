# EXP-20260807-003 波速 −1% 失配偏差非线性复核

## 基本信息

- 实验编号：EXP-20260807-003
- 日期：2026-08-07
- 状态：completed-partial（6/8 探针完成；门控结论已充分）
- 研究主题：[[T01-倒谱分辨率极限]]
- 论文项目：Paper C
- 上游：[[EXP-20260806-002-Fisher信息与CRB可辨识性分析]]（一阶 28–36 m）

## 1. 实验目的

复核 EXP-002 一阶预测：δa/a=−1%（a_data=1435.5，a_model=1450）时深度偏差是否落在 28–36 m 量级（验收：实测/预测 < 2）。

## 2. 研究假设

- H1：非线性全波形 MLE 偏差与一阶 TOF 预测量级一致（比值 < 2）。

## 3. 实验配置

| 参数 | 值 |
|---|---|
| a_data / a_model | 1435.5 / 1450 |
| 方法 | 坐标下降网格 MLE（正确 a 的正演拟合失配数据） |
| radius | 30 格点 |
| 计划探针 | 4 单缝 + 4 双缝 10 m |

## 4. 代码与命令

```bash
python -m analysis.identifiability.run_wavespeed_mismatch --tag probe8 --n-probe 8 --radius 30 --workers 14
# CLI 已扩展：moc_simulate/run_lhs_batch_simulate.py --wavespeed --brunone-k-scale
```

## 5. 输出

`output/analysis/identifiability/wavespeed_mismatch/probe8/wavespeed_mismatch.json`

## 6. 结果

### 单缝（完成 4/4）

| x_true / m | bias_mean / m |
|---:|---:|
| 3600 | +89.1 |
| 3933 | +129.9 |
| 4267 | +130.1 |
| 4600 | −110.4 |

- 中位 |bias| ≈ **120 m**
- 一阶预测 28–36 m
- 比值 ≈ **3.3–4.3** → **门控 ratio<2 未通过**

### 双缝（完成 2/4，其后中止）

共模 bias_mean 较小但 RMSE≈100–130 m（单缝误差大、符号相反或匹配不稳），与「共模深度被波速拉偏」一致。

## 7. 分析与解释

- **H1 不成立（按门控）**：Courant=1 下改 a 会重划分网格并改变离散动力学，一阶连续 TOF 公式低估非线性偏差。
- Paper C 应将「1% → 28–36 m」标为**量级估计 / 推断**，正文写明非线性复核给出 ~100 m 量级。
- 这**加强**而非削弱「实用墙是模型误差」：真实偏差可能比一阶更大。

## 8. 异常与失败

- 探针 7–8 因墙钟过长中止；不影响单缝门控结论。
- 已记入负结果边界：一阶公式适用范围受限。

## 9. 结论

> −1% 波速失配的非线性 MLE 深度偏差中位约 120 m，约为一阶预测的 3–4 倍；一阶公式仅作量级参考。

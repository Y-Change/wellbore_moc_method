# EXP-20260807-002 配对摩阻失配可迁移性（剪刀差）

## 基本信息

- 实验编号：EXP-20260807-002
- 日期：2026-08-07
- 状态：completed
- 研究主题：[[T01-倒谱分辨率极限]] / [[T05-稀疏反卷积]] / [[T07-DCCDM代理模型]]

- 上游：[[EXP-20260806-001-LHS稳态摩阻对照数据集2000]]（配对性更正）、[[EXP-20260806-003-估计器效率验证]]

## 1. 实验目的

在**逐 case 配对**的 brunone ↔ steady 2000 集上，检验差分预测：P0/PhaseNet（brunone 隐含模型）在 steady 上变差；倒谱（纯回声隐含模型）在 steady 上变好。

## 2. 研究假设

- H1：`lhs_dataset_2000` 与 `lhs_dataset_2000_steady` 几何配对（同 case_id 同真值）。
- H2：倒谱 F1@10m 在 steady 上升；P0 在 steady 下降。
- H3：PhaseNet（brunone 训练）在 steady 测试上 F1 显著下降（阈值重校准后仍下降）。

## 3. 实验配置

| 项 | 值 |
|---|---|
| 配对 case | 前 300 个 PASS（古典方法） |
| PhaseNet | close2000_n8192 best.pt；steady 全 test split=300 |
| 容差 | 10 m |
| 阈值 | 旧 0.35；steady val 重校准 → 0.20 |

## 4. 代码与命令

```bash
python -m analysis.identifiability.run_transfer_check --tag main --max-cases 300 --skip-phasenet
# PhaseNet 部分：run_transfer_check.run_phasenet(...)
```

## 6. 结果

### 6.1 配对核查

50/50 case 几何完全一致 → **paired=True**（更正 EXP-001 旧记载）。

### 6.2 古典方法剪刀差（n=300）

| 方法 | brunone F1 | steady F1 | ΔF1 | brunone 中位误差/m | steady 中位误差/m |
|---|---:|---:|---:|---:|---:|
| 倒谱 | 0.232 | **0.642** | **+0.410** | 12.2 | **0.53** |
| P0 | 0.396 | **0.089** | **−0.307** | 16.7 | **41.3** |

**scissors_hold = True**

### 6.3 PhaseNet

| 指标 | 值 |
|---|---:|
| brunone 参考 F1 | 0.746 |
| steady F1（旧阈值 0.35） | 0.228 |
| steady F1（重校准 0.20） | 0.232 |
| ΔF1 vs brunone | **−0.513** |

阈值重校准几乎不挽回 → 掉点来自分布/模型失配，不是阈值未调。

**full_scissors_hold = True**（倒谱↑、P0↓、PhaseNet↓）

## 7. 分析与解释

控制变量是「估计器隐含正演模型与数据生成模型的距离」，而非笼统分布漂移。倒谱在 steady 上接近其纯回声假设故变好；字典/网络在 brunone 上训练/构库，迁到 steady 则崩。

## 8. 异常与失败

无。配对性与剪刀差均按预测方向出现。

## 9. 结论

> 配对摩阻失配剪刀差成立：现有 brunone 基准高估可迁移性；必须报告失配测试集。

# EXP-20260809-004 MOC 管线部署版一步 GN

## 基本信息

- 实验编号：EXP-20260809-004
- 日期：2026-08-09
- 状态：completed
- 上游：[[EXP-20260809-003-MOC管线双缝倒谱初值]]、[[下一阶段执行计划]] N2.5

## 1. 目的

用**精修格点 \(x_{\mathrm{grid}}\) 处重算的 Jacobian** 做一步 Gauss–Newton（`mle_refine_gn`），替代真值处 oracle-GN，完成可部署精修链。

## 2. 配置

| 项 | 值 |
|---|---|
| 脚本 | `run_moc_pipeline.py --deploy-gn` |
| cases | `single_4000`, `dual_10m` |
| init | 簇约束 cepstrum |
| SNR / n_mc | 40 dB / 3 |
| prior | 自动（单 15 / 双 55） |
| GN | `mle_refine_gn` @ `x_grid`，mode=A，1 step |

```powershell
D:\Anaconda\envs\torch24\python.exe -m analysis.identifiability.run_moc_pipeline `
  --tag deploy_gn --cases single_4000,dual_10m --init cepstrum `
  --snr 40 --n-mc 3 --workers 14 --deploy-gn --prior-uncertainty-m 0
```

## 3. 结果（vs oracle 一步 GN @ 真值 J）

| case | med\|grid−oracle\| | med\|hat−oracle\|（deploy GN） | strict |
|---|---:|---:|---|
| single_4000 | 0.012 m | **≈0** | PASS |
| dual_10m | 0.028 m | **≈0** | PASS |

格点搜索已在 CRB 量级；部署 GN 进一步把与 oracle 的差压到数值零附近。

输出：`output/analysis/identifiability/moc_pipeline/deploy_gn/`  
（跑完时 summary 曾因 `}(path)` 粘连笔误报错；case JSON 已完整，summary 已重建。）

## 4. 结论

> **部署版 GN 可用**：不依赖真值 Jacobian；倒谱初值 → MOC 坐标下降 → \(x_{\mathrm{grid}}\) 处重算 J → 一步 GN，单/双缝均 strict PASS。

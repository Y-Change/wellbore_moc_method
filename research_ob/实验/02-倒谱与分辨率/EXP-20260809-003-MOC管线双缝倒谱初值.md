# EXP-20260809-003 MOC 管线双缝（簇约束倒谱初值）

## 基本信息

- 实验编号：EXP-20260809-003
- 日期：2026-08-09
- 状态：completed
- 上游：[[EXP-20260809-002-MOC主路径管线烟测]]、[[下一阶段执行计划]] N2.4

## 1. 目的

在 `dual_10m` 上验证「倒谱粗初值 → MOC 精修」；修复含噪时第二峰漂到趾端旁瓣的问题。

## 2. 关键修复

含噪倒谱原初值可出现 `~4843 m` 假峰（|e|~800 m）。改为：**以首峰为锚，只接纳 5–80 m 簇内后续峰**，缺峰则按末峰+10 m 填充。

## 3. 配置

| 项 | 值 |
|---|---|
| case | `dual_10m` |
| init | cepstrum（簇约束） |
| SNR / n_mc | 40 dB / 3 |
| prior | 55 m → R=41 |
| workers / rounds | 14 / 3 |

```powershell
D:\Anaconda\envs\torch24\python.exe -m analysis.identifiability.run_moc_pipeline `
  --tag dual_cep --cases dual_10m --init cepstrum --snr 40 --n-mc 3 `
  --prior-uncertainty-m 55 --radius-max 50 --workers 14
```

## 4. 结果

| 指标 | 值 | 判定 |
|---|---:|---|
| 中位 \|init−placed\| | 20.6 m | （单次最大初值误差 39.5 m） |
| 中位 \|hat−oracle\| | **0.028 m** | |
| CRB 标尺 | ≈0.031 m | |
| ratio | 0.90 | |
| strict / cell | **PASS / PASS** | |

对照：P0 字典初值在该构型上常吸到深度网格边缘 ~3500 m（|e|~500 m），本试验未用作主初值。

输出：`output/analysis/identifiability/moc_pipeline/dual_cep/`

## 5. 结论

> **双缝 MOC 主路径在簇约束倒谱初值下可过 strict 门槛**（0.028 m < CRB）。  
> 倒谱仍只作初值；含噪假峰必须用局部簇约束，否则精修半径无法覆盖。

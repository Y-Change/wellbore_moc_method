# EXP-20260809-002 MOC 主路径管线烟测（倒谱初值）

## 基本信息

- 实验编号：EXP-20260809-002
- 日期：2026-08-09
- 状态：completed
- 研究主题：[[T01-倒谱分辨率极限]]（初值）+ [[T07-DCCDM代理模型]]（角色降为辅）
- 上游：[[下一阶段执行计划]] N2；策略锁定 **MOC 主 / FNO 辅**

## 1. 目的

验证「倒谱粗初值 → MOC 坐标下降精修」薄封装可跑通，且单缝上贴 oracle / CRB。

## 2. 假设

- H1：倒谱初值误差 ~12 m 量级时，自适应半径可覆盖。
- H2：精修后 |x_hat−x_oracle| < CRB（SNR=40 dB）。

## 3. 配置

| 项 | 值 |
|---|---|
| 脚本 | `analysis/identifiability/run_moc_pipeline.py` |
| case | `single_4000` |
| init | cepstrum |
| SNR / n_mc | 40 dB / 3 |
| prior uncertainty | 15 m → R=14 格 |
| workers | 14 |

## 4. 命令

```powershell
D:\Anaconda\envs\torch24\python.exe -m analysis.identifiability.run_moc_pipeline `
  --tag smoke --cases single_4000 --init cepstrum --snr 40 --n-mc 3 `
  --workers 14 --prior-uncertainty-m 15
```

## 5. 结果

| 指标 | 值 | 判定 |
|---|---:|---|
| 中位 \|init−placed\| | 12.0 m | 与历史倒谱系统差一致 |
| 中位 \|hat−oracle\| | **0.012 m** | |
| CRB_A@40 | 0.025 m | |
| ratio | 0.46 | |
| strict / cell | **PASS / PASS** | |

输出：`output/analysis/identifiability/moc_pipeline/smoke/`

## 6. 结论

> **MOC 主路径烟测通过**：倒谱只作初值，精修归 MOC，单缝可达 CRB 量级。FNO 非本管线必需。

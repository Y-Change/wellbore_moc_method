# EXP-20260730-024 T04 波形退化指标审计

## 1. 实验目的

从既有 30 组规定 \(k\times D\) 时间序列重新导出可审计的 STFT 频带能量、峰漂移、EST 和双峰对比度，统一公式、参考和阈值；用合成双峰单元测试约束 \(C_v\)；核对 Paper BC 锚点数字。不重跑 MOC。

## 2. 研究假设

- H1：共同 STFT 参考（窗、重叠、dB 参考写入 manifest）下，高频相对低频的选择性衰减随 \(k\) 增强。
- H2：统一定义的峰谷对比度 \(C_v=(P_{\min}-V)/P_{\min}\) 在合成双峰上单调，并在 30 工况上随 \(k\) 增大、\(D\) 减小而下降；该量**不**被解释为 Rayleigh 最小缝距。

## 3. 实验配置

| 参数 | 数值 | 说明 |
|---|---|---|
| 工况 | 6 \(k\) × 5 \(D\) = 30 | 复用既有 CSV，不重跑 |
| \(k\) | 0, 0.01, 0.02, 0.05, 0.1, 0.2 | 规定常数；\(k=0\) 为稳态 |
| \(D\) | 5, 10, 20, 50, 100 m | 四条等缝，首缝 4100 m |
| 信号 | \(\mathrm{d}H/\mathrm{d}t\) | `np.gradient` |
| 默认窗 | [6.5, 7.5] s | 首缝几何到时 ≈ 6.655 s |
| 寻峰 | height = 0.1 max，distance = 2 ms | 预注册 |
| EST | 正部能量 E10–E90 | 不是 FWHM |
| \(C_v\) | \((P_{\min}-V)/P_{\min}\in[0,1]\) | <2 峰记 0 |
| STFT | Hann，nperseg=128，noverlap=120，scaling=spectrum | 段 [6.4, 7.2] s |
| dB 参考 | \(10\log_{10}(E(k)/E(k=0,\text{同}D))\) | 写入 manifest |
| 频带 | 0–20、20–60、60–150 Hz | STFT 与窗内 rFFT 对照 |
| 窗敏感 | 四窗含默认窗 | 仅锚点 D=20 m、k=0.2 |

## 6. 结果

### 单元测试

等幅高斯 \(\sigma=20\,\mathrm{ms}\)：分离 0 时 \(n_{\mathrm{peaks}}=1\)、\(C_v=0\)；分离 160 ms 时 \(C_v=0.999>0.8\)；\(C_v\) 随分离度单调不减。脚本内断言通过。

### 锚点 D=20 m、k=0.2（相对同间距 k=0）

| 量 | 数值 |
|---|---:|
| 峰漂移 | **277.0 ms** |
| EST（绝对） | **101.0 ms** |
| \(\Delta\)EST | 100.0 ms |
| 标量 \(a/2\) 换深度 | 200.8 m（仅示意，不是 Re 相关 k 的倒谱偏差） |
| \(C_v\) / 峰数 | 0 / 1 |
| 首峰 FWHM | 31 ms（k=0.1 时为 38 ms，假性收窄） |
| STFT 0–20 Hz | −12.9 dB |
| STFT 20–60 Hz | −25.4 dB |
| STFT 60–150 Hz | **−44.1 dB** |
| rFFT 60–150 Hz | −44.9 dB |
| \(a_{f0}\) / 降幅 | 1254 m/s / 11.0% |
| \(a_{\mathrm{onset}}\) / 降幅 | 1432 m/s / 1.3% |
| \(a_{\mathrm{peak}}\) / 降幅 | 1383 m/s / 4.7% |

k=0.1、同一 D：峰漂移 138 ms，STFT 60–150 Hz −42.8 dB。

### 窗敏感性（D=20 m、k=0.2）

[6.5, 7.5]、[6.4, 7.2]、[6.6, 7.0]、[6.5, 8.0] 四窗的峰漂移与 EST **均为 277 ms 与 101 ms**。

### 其他观察

- k=0、D=20 m 时 10% 峰高阈值检出 3 个峰而非 4 个；不把“四峰尽数可分”写成检测结论。
- D=100 m 的 EST 含后缝，不能当首缝宽度；锚点保持 D=20 m。
- 20–60 Hz 在 k=0.2 处比 k=0.1 回升约 1.5 dB，中频不是严格单调；高频 60–150 Hz 在 D=20 m 上随 k 单调下降。
- 旧“60–150 Hz >40 dB”在本清单参考下成立（k=0.2 为 −44.1 dB），必须同时报告低频对照与 dB 参考。

## 7. 分析与解释

- **H1 成立**：高频相对低频选择性衰减随 k 增强；共同参考已写入 manifest。
- **H2 部分成立**：合成双峰单调；30 工况上小 D、大 k 时 \(C_v\to 0\)。按预注册，**不**把热力图写成最小可分辨缝距表，也不恢复 Rayleigh 0.81 分数作为主文指标。
- 峰漂移 277 ms 与旧 `metrics_summary.csv` / EXP-020 一致，公式现可复算。
- 26%/74%（onset 72 ms / 其余 205 ms）仍是当前 onset 阈值下的操作分解，不是唯一物理分解。

## 9. 结论

> 规定 k 矩阵的峰漂移 277 ms、EST 101 ms、STFT 60–150 Hz −44.1 dB（相对同间距 k=0）可在预注册公式下复算；频率选择性耗散成立；\(C_v\) 只作融合趋势，不作分辨率墙。

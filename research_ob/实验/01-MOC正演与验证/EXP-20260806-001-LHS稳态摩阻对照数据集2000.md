# EXP-20260806-001 LHS 稳态摩阻对照数据集（2000）

## 基本信息

- 实验编号：EXP-20260806-001
- 日期：2026-08-06-19:46
- 状态：completed
- 研究主题：[[T01-倒谱分辨率极限]]、[[T04-Brunone频散效应]]
- 论文项目：Paper B（steady–Brunone 对照输入）

## 1. 实验目的

生成与 `output/lhs_dataset_2000`（Brunone）同规格的 **steady 摩阻** LHS 数据集，供后续倒谱分辨率、衰减与 Brunone 波形退化对照使用。

## 2. 研究假设

- H1：在相同 LHS 采样区间与仿真时长下，steady 可稳定批量化生成 2000 组井口水击波形。
- H2：本集与 brunone 集在摩阻模型上构成可对照的平行语料（几何参数由当前 LHS 生成器独立采样，见第 8 节）。

## 3. 实验配置

| 参数 | 数值 | 说明 |
|---|---:|---|
| n_samples | 2000 | 对齐 `lhs_dataset_2000` |
| friction | steady | 本实验变量 |
| tf | 50.0 s | 与 brunone 集一致 |
| dt | 0.001 s | |
| workers | 14 | |
| seed | 42 | 当前代码默认种子 |
| n_frac | 1–6 | |
| spacing | 5–20 m | 相邻簇硬约束 |
| 缝网区间 | 3500–4800 m | |
| Cf log | [-8.7, -5.5] | |
| kleak log | [-6.0, -3.0] | |

对照基线：`output/lhs_dataset_2000`（friction=`brunone`，tf=50 s，2000/2000 PASS，2026-07-30）。

## 4. 代码与命令

- 代码入口：`moc_simulate/run_lhs_batch_simulate.py`
- 配置文件：`moc_simulate/lhs_config.py`（`LHS_PARAM_RANGES` / `SIM_CONFIG`）
- 运行命令：

```bash
python moc_simulate/run_lhs_batch_simulate.py \
  --n-samples 2000 --workers 14 --tf 50.0 \
  --friction steady \
  --out-dir output/lhs_dataset_2000_steady \
  --seed 42
```

- 随机种子：42

## 7. 分析与解释

- 是否支持假设：H1 支持（全量 PASS）。H2 在采样区间与协议对齐意义上成立。
- **配对性更正（2026-08-07）**：磁盘核查表明 `lhs_dataset_2000_steady` 与 `lhs_dataset_2000` 的 `positions/Cf/kleak` **逐 case 完全一致**（2000/2000；抽样 50/50 亦一致）。先前「非配对」判断有误——当前 `generate_lhs_params(seed=42)` 可复现 brunone 集几何。下游配对失配实验见 [[EXP-20260807-002-失配可迁移性剪刀差]]。
- 物理解释：本实验只交付正演数据，不做倒谱/衰减分析。

## 8. 异常与失败

- ~~与 `lhs_dataset_2000` 的几何不对齐~~：**已更正**。旧笔记基于生成器版本猜测；以磁盘 metadata / npz 真值为准，两集为严格摩阻配对语料。
- 若未来 `generate_lhs_params` 再变更，应用 metadata 回放而非依赖 seed 复现。

## 9. 结论

> 一句话结论：已生成 `output/lhs_dataset_2000_steady`（2000/2000 PASS，tf=50 s，间距 5–20 m），与既有 brunone `lhs_dataset_2000` **逐 case 几何配对**（仅 friction 不同）。

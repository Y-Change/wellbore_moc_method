# EXP-20260730-006 P0-A count 头 + 密间距过采样（N=16384 窄 FWHM）

## 基本信息

- 实验编号：EXP-20260730-006
- 日期：2026-07-30
- 状态：completed（subset512 **FAIL**；相对 EXP-004 **未改善**）
- 研究主题：[[T07-DCCDM代理模型]]
- 前序：[[EXP-20260730-004]]、[[EXP-20260730-005]]

## 1. 实验目的

固定 EXP-004 的 N=16384 + 窄 FWHM，检验 count 辅助头（CE + 推理 top-K）与 5–10 / 高缝数过采样能否抬升 held-out。

## 2. 研究假设

- H1：count 头改善 exact-count / 多缝 F1。→ **不支持**
- H2：过采样抬升 5–10 召回。→ **不支持**
- H3：若仍 FAIL，瓶颈更偏表示/物理先验。→ **倾向支持**

## 3. 实验配置

| 参数 | EXP-004 | 本实验 |
|---|---|---|
| manifest | n16384 窄 FWHM | 同左 |
| 损失 | focal+0.5·dice | +0.25·CE(count) |
| 采样 | 均匀 | 5–10×2，n≥4×2 |
| 检测 | 纯峰值 | count prior → top-K |

Run：`output/direct_inverse/runs_close2000_n16384_count/20260730-171500-458955-p0a-subset512-...`

## 4. 结果（subset512）

| 指标 | EXP-004 | **EXP-006** | 变化 |
|---|---:|---:|---|
| Gate | FAIL | **FAIL** | — |
| F1 | **0.690** | 0.644 | −0.046 |
| P / R | 0.794 / 0.611 | 0.750 / 0.564 | 双降 |
| exact / MAE | **40.6% / 0.87** | 32.8% / 0.98 | exact↓ |
| soft Dice | 0.528 | 0.484 | ↓ |
| 5–10 F1 / exact | **0.655 / 21.7%** | 0.613 / 14.5% | ↓ |
| best epoch | 42 | 49 | — |

分层：singleton 仍强（F1≈0.98）；5–10 / 10–15 仍是短板。

## 5. 结论

> **count 头 + 过采样未打穿 held-out，且相对窄 FWHM 基线略退步。** 当前近距泛化瓶颈不像是「缺计数监督 / 采样不均」这么简单。

## 6. 下一步候选

- 回到 N=8192（held-out 最好 F1=0.746）做 count 头，或只评 spacing≥10 m
- 物理特征 / LISTA 稀疏基线对照
- 暂缓继续堆 N=16384 训练技巧

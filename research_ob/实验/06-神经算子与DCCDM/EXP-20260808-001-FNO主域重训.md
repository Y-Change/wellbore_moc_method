# EXP-20260808-001 FNO@lhs_dataset_2000 重训与波形门槛

## 基本信息

- 实验编号：EXP-20260808-001
- 日期：2026-08-08
- 状态：completed
- 研究主题：[[T07-DCCDM代理模型]]
- 上游：[[EXP-20260807-004-FNO代理精度门槛]]、[[下一阶段执行计划]] P0

## 1. 实验目的

在 Paper C 主研究域 `output/lhs_dataset_2000` 上重训 FNO 正演代理，使波形精度过咨询门槛，作为后续 FNO-MLE 反演门槛的前置条件。

## 2. 研究假设

- H1：同分布重训后，held-out 中位相对 L2 < 0.05。
- H2：权重单独归档后，不破坏 6000 域旧模型（`output/models/fno_surrogate_best.pt`）。

## 3. 实验配置

| 参数 | 数值 | 说明 |
|---|---:|---|
| data-dir | `output/lhs_dataset_2000/data` | 2000 条 NPZ，tf=50 |
| out-dir | `output/models/fno_close2000` | 新权重目录 |
| epochs | 100 | |
| batch-size | 32 | |
| lr | 1e-3 | AdamW + Cosine |
| width / modes / layers | 64 / 32 / 4 | 与旧结构一致 |
| n-time | 4096 | |
| 环境 | `D:\Anaconda\envs\torch24` | CUDA，RTX 4060 Ti |

## 4. 代码与命令

- 代码入口：`neural_operator/train_surrogate.py`
- 验收：`python -m neural_operator.eval_surrogate`
- 训练命令：

```powershell
$env:PYTHONIOENCODING='utf-8'; $env:PYTHONUNBUFFERED='1'
D:\Anaconda\envs\torch24\python.exe neural_operator/train_surrogate.py `
  --data-dir output/lhs_dataset_2000/data `
  --out-dir output/models/fno_close2000 `
  --epochs 100 --batch-size 32 --lr 1e-3
```

- 验收命令：

```powershell
D:\Anaconda\envs\torch24\python.exe -m neural_operator.eval_surrogate `
  --ckpt output/models/fno_close2000/fno_surrogate_best.pt `
  --data-dir output/lhs_dataset_2000/data `
  --out-dir output/analysis/identifiability/fno_accuracy/close2000_retrain
```

## 5. 数据与输出

- 输入：`output/lhs_dataset_2000/data`（2000 NPZ）
- 输出：`output/models/fno_close2000/`（best.pt、log.csv、eval 图）
- 验收：`output/analysis/identifiability/fno_accuracy/close2000_retrain/`
  - `fno_accuracy.json`、`per_sample_metrics.npz`、`fno_vs_moc_overlay.png`、`rel_l2_hist.png`

## 6. 结果

### 训练

| 项 | 值 |
|---|---:|
| 总耗时 | 30.49 min |
| Best val loss（复合物理损失） | 151.691（epoch 93） |
| 约每 epoch | ~18.2 s |

### 波形门槛（held-out n=300）

| 指标 | 结果 | 门槛 | 判定 |
|---|---:|---:|---|
| 中位 rel L2 | **0.0292** | < 0.05 | **PASS** |
| 均值 rel L2 | 0.0360 | — | — |
| p90 rel L2 | 0.0644 | — | — |
| 中位 RMSE | 8.63 | — | — |
| 单次前向 | ~1.76 ms（CUDA） | — | — |

对照旧权重同域（EXP-004）：中位 rel L2 **0.319 → 0.029**。

## 7. 分析与解释

- **支持 H1**：同分布重训后波形精度与 6000 域旧权重同量级（~0.029）。
- **支持 H2**：新权重在 `fno_close2000/`，未覆盖 `output/models/fno_surrogate_best.pt`。
- 解释：EXP-004 失败是**域不匹配**（旧权重训于 6000），非 FNO 能力上限。

## 8. 异常与失败

- 默认 `D:\Anaconda\python.exe` 为 CPU-only torch；训练必须用 `torch24` 环境，否则不可接受地慢。
- 训练 stdout 在后台会话中一度未刷出；以 `train_surrogate_log.csv` 为准监控。

## 9. 结论

> 主域 FNO 波形门槛 **PASS**（中位 rel L2≈0.029）；可进入 P1 反演门槛（FNO-MLE vs MOC-MLE 位置差 vs CRB）。波形 PASS ≠ 反演 PASS。

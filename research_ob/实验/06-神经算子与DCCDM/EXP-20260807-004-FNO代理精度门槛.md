# EXP-20260807-004 FNO 正演代理波形精度门槛

## 基本信息

- 实验编号：EXP-20260807-004
- 日期：2026-08-07
- 状态：completed
- 研究主题：[[T07-DCCDM代理模型]]（服务 [[下一阶段执行计划]] N2）
- 上游：[[技术路线与核心问题]]

## 1. 实验目的

在启动「FNO 上梯度全波形反演」之前，先量化现有权重 `fno_surrogate_best.pt` 的波形相对 L2，避免用未验证代理替代 MOC。

## 2. 研究假设

- H1：在训练同分布 held-out 上，中位相对 L2 < 0.05（咨询性门槛）。
- H2：在 Paper C 主域 `lhs_dataset_2000`（tf=50，近距）上同样达标。

## 3. 配置

| 项 | 值 |
|---|---|
| 权重 | `output/models/fno_surrogate_best.pt` |
| 结构 | width=64, modes=32, layers=4, N=4096 |
| 脚本 | `python -m neural_operator.eval_surrogate` |

## 4. 命令

```bash
python -m neural_operator.eval_surrogate \
  --ckpt output/models/fno_surrogate_best.pt \
  --data-dir output/lhs_dataset_6000/data \
  --out-dir output/analysis/identifiability/fno_accuracy/on_lhs6000

python -m neural_operator.eval_surrogate \
  --ckpt output/models/fno_surrogate_best.pt \
  --data-dir output/lhs_dataset_2000/data \
  --out-dir output/analysis/identifiability/fno_accuracy/main
```

## 5. 结果

| 数据域 | n_val | 中位 rel L2 | 中位 RMSE | advisory (<0.05) | 单次前向 |
|---|---:|---:|---:|---|---:|
| `lhs_dataset_6000` | 900 | **0.029** | 8.4 | **PASS** | ~9.5 ms CPU |
| `lhs_dataset_2000` | 300 | **0.319** | 94.2 | **FAIL** | ~9.4 ms CPU |

训练日志最佳 composite val_loss≈162.75，与 6000 域 MSE 量级一致；权重很可能在 6000 域（或同规格旧 `lhs_dataset`）上训练，**未覆盖** close2000 / tf=50 主研究域。

## 6. 结论

> 现有 FNO 权重在 6000 域波形精度可接受，但在 Paper C / PhaseNet 主域 `lhs_dataset_2000` 上相对 L2≈0.32，**不得**用于该域的梯度反演原型。下一步须在 2000 域重训或域适应后再谈反演门槛（FNO-MLE vs MOC-MLE）。

# EXP-20260730-003 P0-A 近距加密网格（N=8192）对照

## 基本信息

- 实验编号：EXP-20260730-003
- 日期：2026-07-30
- 状态：completed（Oracle 改善已证实；subset512 F1 过线但计数 gate FAIL）
- 研究主题：[[T07-DCCDM代理模型]]
- 对照基线：[[EXP-20260730-002-P0A近距5-20m再验证]]（N=4096，bin≈8.85 m）

## 1. 实验目的

检验将重采样序列从 4096 加长到 8192（加密深度格点）后，近距 5–20 m 事件协议的 Oracle 上限与 memorization / held-out 是否显著改善。

## 2. 研究假设

- H1：`bin_depth` 从 ≈8.85 m 降到 ≈4.43 m 后，Oracle 在 5–10 m 带的 exact-count / F1 应明显上升。
- H2：overfit1（15–20 m）仍应 PASS。
- H3：overfit16 / subset512 事件指标应相对 N=4096 改善，但计数仍可能被 5–10 m 拖累。

## 3. 实验配置

| 参数 | N=4096（EXP-002） | N=8192（本实验） |
|---|---:|---:|
| `seq_length` | 4096 | **8192** |
| `tf` | 50 s | 50 s（同数据） |
| bin_depth | ≈8.85 m | ≈**4.43 m** |
| 标签 FWHM / 检测容差 | 8.85 m | 4.43 m |
| 数据 | lhs_dataset_2000 | 同左（仅重采样更密） |
| split | 1400/300/300 | 同左（同一 split seed） |

## 4. 代码与命令

## 5. 结果

| 指标 | N=4096 | N=8192 | 变化 |
|---|---:|---:|---|
| Oracle physical F1 | 0.785 | **0.962** | +0.177 |
| Oracle exact-count | 28.1% | **77.3%** | +49.2 pp |
| Oracle 5–10 F1 / exact | 0.733 / 0% | **0.943 / 58%** | 显著改善 |
| Oracle 10–15 / 15–20 | 弱/近通 | **均 1.0** | 达满分 |
| Overfit1 | PASS | PASS | 保持 |
| Overfit16 F1 / exact | 0.833 / 7/16 | **0.953 / 12/16** | 改善；gate 仍 FAIL |
| Subset512 physical F1 | 0.584 | **0.746** | +0.162（过软 F1 阈值 0.70） |
| Subset512 P / R | 0.979 / 0.416 | 0.876 / 0.649 | 召回升 |
| Subset512 exact / MAE | 21.1% / 2.01 | **30.5% / 1.08** | 改善；计数 gate FAIL |
| Subset512 阈值 | 0.55 | 0.35 | — |

### Subset512 分层（N=8192）

| 带 | F1 | exact-count |
|---|---:|---:|
| singleton | 0.958 | 91.3% |
| 15–20 | 0.895 | 55.6% |
| 10–15 | 0.786 | 18.5% |
| 5–10 | 0.702 | 11.6% |

## 6. 结论

> 加密到 N=8192 把近距 Oracle 上限从 0.79 抬到 0.96，held-out F1 从 0.58 抬到 **0.75**；exact-count 仍约 30%，失败集中在密间距带。网格加密必要且有效，计数稳健性仍需更密网格或收窄放行池。

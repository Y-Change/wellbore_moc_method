# EXP-20260730-007 水击诊断整体优化与渐进式反演路线图

## 1. 计划背景与问题诊断

基于对全系统正演、信号处理、神经反演与物理机理的全面审查，识别出当前阶段四大核心瓶颈：

1. **T07 直接反演高 N 泛化衰退**：N=16384 时 bin≈2.21 m，Oracle 打穿 5–10 m 密集缝，但 subset512 held-out F1 为 0.690（低于 N=8192 的 0.746）。根因在于缺乏 count 辅助头、密间距过采样及物理特征（倒谱/包络）输入。
2. **T06 频散补偿仍为学习型 CNN 壳**：`dedispersion.py` 缺乏 Brunone 频散物理算子，致使 Paper 2 最核心的"补偿恢复分辨率"论点缺乏数值支撑。
3. **T05 稀疏反卷积与 T07 神经反演脱节**：二者数据集与评估指标独立，缺乏统一的 F1 / Precision / Recall / Depth Error 评估框架。
4. **Paper 1 缺无噪声与鲁棒性消融**：需补全 SNR=10~40 dB 下的倒谱定位退化曲线。

### 2.2 T06 物理频散补偿算子设计

建立基于 Brunone 频散等效相速度的相位后向传播补偿算子：

$$\phi_{\text{corr}}(\omega, d) = \omega \cdot \left( \frac{2d}{c_{\text{eff}}(\omega)} - \frac{2d}{c_0} \right)$$

其中：
$$c_{\text{eff}}(\omega) \approx c_0 \left( 1 - \frac{k_b V_0}{4 D \sqrt{2\nu\omega}} \right)$$

**实施步骤**：
1. 实现 `analysis/dispersion_compensation/dispersion_compensation.py`。
2. 实现已知 $k_b, V_0$ 下的 Phase Shift Migration 距离域映射。
3. 验证 Brunone 强频散工况下（$k=0.02, 0.05$）密缝间距（$D=20\text{ m}$）倒谱峰及稀疏解的恢复效果。

### 2.3 统一评估框架构建

新建 `analysis/unified_evaluation/`，拉通所有定位方法：

- **受评算法**：1D 倒谱、L1 反卷积、盲反卷积、PhaseNet (P0-A/B/P1)、LISTA (P2)。
- **统一测试集**：`lhs_dataset_2000` (5–20 m) 及标准 `lhs_dataset` (≥50 m)。
- **核心指标**：
  - Event F1, Precision, Recall ($\text{tolerance\_m} = \text{bin\_depth}$)
  - Exact Count Accuracy (%) 与 Count MAE
  - Depth Error Median & P95 (m)

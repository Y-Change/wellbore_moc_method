# 双峰分离判据与 EST 指标

## 1. 三个不同问题

- **双峰分离**：两个相邻反射波包能否形成两个峰和足够深的谷。
- **峰宽**：单个或融合波包在某个幅值水平上的宽度。
- **能量弥散时间 EST**：波包正部能量从 E10 到 E90 的时间跨度。

三者不可互换；它们也不同于倒谱谱支撑宽度。

## 2. 双峰分离指标

可选一种公式并全文一致：

\[
R_v=V/P_{\min}
\]

或峰谷对比度：

\[
C_v=(P_{\min}-V)/P_{\min}=1-R_v,
\]

其中 `V` 为两峰之间谷值，`P_min` 为较小峰值。若使用 Rayleigh 类阈值，必须从同一公式推导，不能在注释、代码和图表中混用 0.81 与 `1-0.81`。

由于水击反射峰不是理想 Airy/sinc 点扩散函数，建议在论文中称“操作性双峰分离指数”，并给出阈值敏感性。

## 3. EST

当前实现使用正部波形能量的累积分布：

\[
EST=t_{E90}-t_{E10}.
\]

EST 对强退化、非对称低矮波包通常比 FWHM 更稳定，但它可能包含多峰融合和分析窗影响，因此不能无条件解释为严格频散宽度。

## 4. 审计要求

- 用合成双峰验证完全重叠、部分分离和深谷情况下指标单调变化。
- 预注册峰检测、谷搜索、阈值和缺峰处理。
- 保存机器可读 CSV/JSON，再据此绘制热力图。
- 对分析窗、阈值和噪声做敏感性分析。

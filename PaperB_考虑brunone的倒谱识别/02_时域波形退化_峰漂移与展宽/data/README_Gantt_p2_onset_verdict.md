## 2. 三个核心问题判决定论 (审定定稿版)

1. **常数 $k=0.01$ 单缝：onset 的 $|\Delta x|$ 是否 $<3\,\mathrm{m}$，peak/cep 是否仍约 9 m？**  
   **完全成立。** 在 $n=1, k=0.01$ 下，onset 绝对误差 $\Delta x = \mathbf{-1.58\,\mathrm{m}}$（$|\Delta x| < 2\,\mathrm{m}$，与稳态基准 $-1.58\,\mathrm{m}$ 一致）；而峰值与倒谱时钟绝对误差均为 $\Delta x = \mathbf{+8.58\,\mathrm{m}}$，相对稳态基准的后移量严格等于 $\mathbf{+9.43\,\mathrm{m}}$。
2. **leakoff 动态 $k(Re)$ 单缝：onset 的 $|\Delta x|$ 是否明显小于倒谱？是否还落在 10–20 m？**  
   **完全成立。** 在动态 $k(Re)$ 单缝工况下，两套倒谱估计器均显著偏深：历史 1D 实倒谱偏差为 **$+11.80\,\mathrm{m}$**（与峰时钟 $+10.75\,\mathrm{m}$ 紧密对齐），冻结全谱 $|C(\tau)|$ 倒谱偏差为 **$+18.73\,\mathrm{m}$**，二者均落在 $10 \sim 20\,\mathrm{m}$ 系统性偏深区间；而改用 onset 时钟后，绝对误差收敛至 $\Delta x_{\text{onset}} = \mathbf{+1.33\,\mathrm{m}}$，回落到与稳态对照（$-1.58\,\mathrm{m}$）相当的米级物理噪声水平。
3. **科学假说 H1 审定裁决**：  
   **H1 在单缝机制上成立。** 非定常摩阻下，凡是跟随耗散子波能量重心演化的特征时钟（峰时钟、能量中位时钟、倒谱时钟）在弱阻尼下均产生稳定的系统性偏深；在 $k(Re)$ 下倒谱估计器比峰时钟偏深更显著（$+18.73\,\mathrm{m}$ vs $+10.75\,\mathrm{m}$，同号同量级）；而改用物理第一断点（onset 时钟）可将上述系统性偏深统一拉回至 $\sim 1\,\mathrm{m}$ 级别。

# 05 非稳态摩阻参数敏感性分析模块

## 模块定位
本模块系统剖析物理参数与流动环境对非稳态阻尼强度及倒谱特性的控制规律，绘制全工况参数响应曲面，建立从工程流动/流变参数到倒谱特性的基础映射。

## 核心参数分析维度
1. **Brunone 常数系数 $k$ 的主效应分析**：
   - 固定几何与边界下，评估 $k \in [0, 0.2]$ 驱动的时域能量弥散时间 EST、STFT 频带能量衰减 (dB)、倒谱特征峰宽及倒时偏移量 $\Delta\tau$ 的响应曲面。

2. **雷诺数自适应动态 $k(Re)$ 与时空分布**：
   - 分析停泵全过程中管内局部流速 $V(x,t)$ 与局部雷诺数 $Re(x,t)$ 的时空衰减演化；
   - 提取实际井筒中实现的生效动态 $k$ 概率分布（加权均值、中位数、P95），对比外加常数 $k$ 的差异。

3. **流体流变性（运动粘度 $\nu$）的敏感性响应**：
   - 考察滑溜水（低粘/高 Re）、线性胶（中粘/中 Re）与交联冻胶（高粘/低 Re）三种典型体系在雷诺数区间与非稳态阻尼上的阶梯性差异；
   - 评估不同粘度流体下倒谱峰钝化与倒时漂移的梯度演变。

4. **几何与流动边界（管径 $D_p$、初始流速 $V_0$）的交互作用**：
   - 探究小管径（高壁面剪切）与大流速对非稳态阻尼项的放大与调制规律。

## 辩证分析预案
- **主假说**：粘度越大，雷诺数越低，Brunone 阻尼越强，倒谱退化越显著。
- **备选解释预案**：
  1. *若在层流/紊流过渡区（$Re \sim 2000$）出现非单调的倒谱响应波动*：依据 Vardy 剪切衰减系数公式在层流常数分支（$C = 4.76\times 10^{-3}$）与紊流动态分支之间的分段衔接与流态转换物理机制进行合理解释；
  2. *若大管径下非稳态摩阻的相对贡献下降*：从边界层剪切应力厚度与管径之比 $\delta / D_p$ 的尺度效应进行合理解释。

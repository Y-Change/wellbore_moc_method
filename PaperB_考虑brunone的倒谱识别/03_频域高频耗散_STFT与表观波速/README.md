# 03 频域高频耗散_STFT与表观波速模块

## 模块定位
从傅里叶变换、短时傅里叶变换（STFT）以及表观速度（Apparent Wave Speed）的分裂现象，深入揭示非稳态阻尼引起的“频率选择性耗散（Frequency-Selective Dissipation）”与时钟分道扬镳的物理本质。

## 目录结构
- `./code/`: STFT 时频分析脚本 (`plot_tf_dispersion.py`) 与 CWT 小波频散脚本 (`plot_cwt_dispersion.py`)；
- `./data/`: 频带能量衰减统计表 (`band_energy.csv`)；
- `./figures/`: STFT 共同参考时频谱、频带能量衰减柱状图与表观波速分化图。

## 核心物理量与数据纪律
1. **频率选择性耗散（以弱阻尼档为主要依据）**：
   - 弱阻尼档 $k=0.01$ (现场核心档)：
     * 低频段（0–20 Hz）：衰减 **$-1.6\text{ dB}$**；
     * 中频段（20–60 Hz）：衰减 **$-4.7\text{ dB}$**；
     * 高频段（60–150 Hz）：衰减 **$-17.0\text{ dB}$**（高频谐波产生中等抹平）。
   - 中强阻尼档 $k=0.02$：
     * 低频段：衰减 **$-2.7\text{ dB}$**；
     * 中频段：衰减 **$-9.9\text{ dB}$**；
     * 高频段：衰减 **$-26.2\text{ dB}$**。
   - 极限应力测试档 $k=0.2$ (仅列 SI 附录)：
     * 低频段：衰减 $-12.9\text{ dB}$；
     * 高频段：衰减 $-44.1\text{ dB}$。

2. **表观速度与特征时钟分叉**：
   - 起跳波速 $a_{\text{onset}}$：在 $k=0.01$ 时为 $1450\text{ m/s}$（相对稳态 $1451\text{ m/s}$ **仅下降 0.02% / 1 ms**），首波前以介质真实声速传播；
   - 峰值波速 $a_{\text{peak}}$：在 $k=0.01$ 时为 $1447\text{ m/s}$，峰值到时滞后 $13.0\text{ ms}$；
   - 基频波速 $a_{f0} = 4L f_0$：在 $k=0.01$ 时为 $1408\text{ m/s}$。

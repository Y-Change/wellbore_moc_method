## 0. 摘要与研究定位

本研究面向水力压裂停泵水击（water hammer）信号的正演建模与逆演解释，研究对象限定为：可压缩单相井筒一维瞬变流、多个位置未知的射孔簇/裂缝支路、非线性孔眼节流、裂缝储容–惯性–漏失（RCI）集总动力学、Zielke / Vardy–Brown 频变非定常摩阻，以及**单个井口高频压力序列**观测。方法学核心是特征线–阻抗跳跃神经算子（CJ-NO）：将全井算子分解为特征坐标下的段传播算子 $\mathcal{P}_j$（嵌入指数递归记忆核）与可微隐式 Newton 节点跳跃算子 $\mathcal{N}_j$（强约束质量与压力迹闭合），并以摊销编码 + FIM 子空间投影完成两级反演。

### 0.1 创新定位（交集式表述，禁止绝对化）

本文创新立足于"**未知多簇非连续节点 + 频变记忆摩阻 + 单点高频井口观测可辨识性**"三要素的系统性交集：在已核验文献范围内，尚未有工作在同一模型中同时（i）以结构保持方式处理可变数目、位置未知的强奇异阻抗跳跃节点，（ii）嵌入 Zielke/Vardy–Brown 记忆卷积并与 Brunone 模型严格分离消融，（iii）对单点井口观测给出带不确定度的逐簇联合参数可辨识性边界。全文一律使用"在已核验文献范围内尚未同时展示/统一验证"的措辞，禁止"国际上首次、完全空白、彻底解决、现有 PINN 全部失效"等无法证伪的表述。

### 0.3 四个可证伪假设（继承总方案 §0，绑定量化指标）

- **H1（结构保持增益）**：在未见簇布局（OOD）上，CJ-NO 相对同预算 vanilla FNO/DeepONet 将节点邻域（$|x-x_j|\le 2\Delta x$）相对 $L_2$ 误差与首波相位误差 $\Delta\phi_1$（定义为首波往返周期 $4L/a$ 的百分比，见 §4.3）至少降低 50%，节点守恒残差 $R_{jump}\le 10^{-3}$（基线典型 $\ge 10^{-2}$）。**预注册三段式判定**：改进 $\ge 50\%$ → 强主张成立；改进落入 $[20\%, 50\%)$ → 主张降级为"部分改进"，摘要与结论采用预写限定措辞模板（"CJ-NO 带来一定但未达预期幅度的改进"）；改进 $<20\%$ → H1 被否证，A1b/A4a/A4b 消融结果升格为负结果主体。H1 证据链的必要组成是 A1b 受控实验（硬隐式节点层 vs 同架构软惩罚层，见 §6.2）。
- **H2（摩阻模型可分离）**：Zielke/VB 与 Brunone 两分支在 1–100 Hz 分频带衰减率上的差异可由消融 A2 分离，且指数核拟合误差（相对 $L_2$<1%、相位 <1°）与网络误差分开报告；若两模型在全部频带差异小于网络误差本身，则该频带内不宣称摩阻模型可辨识。
- **H3（部分可辨识性）**：单点井口波形只能稳定识别 FIM 有效子空间内的联合量（如 $C_d A_{perf}$、等效端口导纳）；以 profile likelihood 与后验 coverage（目标 0.90–0.98）刻画边界。**预注册三分支判定**（阈值体系与 §5.2/§5.3 双阈值方案统一）：(a) 全参数 coverage 合格且白化雅可比条件数 $<10^3$（即 FIM 条件数 $<10^6$，谱约定见 §5.2）→ H3 被否证（全可辨识）；(b) 仅可识别子空间内 coverage $\in [0.90, 0.98]$ → H3 成立；(c) 子空间内 coverage 也出界 → 标记"方法未达标"，H3 不作结论并触发 §5.5 降级路径（该分支显式写入 §5.5 降级表）。
- **H4（有条件加速）**：CJ-NO 加速仅在查询量 $M > M_{\text{break-even}} = (T_{label}+T_{train})/(T_{MOC}-T_{infer})$ 时成立；速度报告必须含标签生成、训练、I/O 与反演迭代成本，未达标照实给 Pareto 前沿。**否证判据**：预注册典型反演场景总查询量 $M_{typ}$（按 §5 反演流程的实际迭代×batch 数核算并写入 configs）；若 $M_{typ} < M_{\text{break-even}}$，则"加速"主张不进入摘要与结论，仅在速度核算节如实给出。

## 2. 统一物理模型与数学假设声明

### 2.1 井筒双曲方程组（流量形式，SI 单位）

$$r_Q = Q_t + gA\,H_x + \frac{fQ|Q|}{2DA} + J_{u,Q} = 0, \qquad r_H = H_t + \frac{a^2}{gA} Q_x = 0$$

- 非定常摩阻源项 $J_{u,Q}$ 的单位为 $\mathrm{m^3\,s^{-2}}$，换算式 $J_{u,Q} = 4A\,\tau_{w,u}/(\rho D)$；**禁止混写 $gAJ$ 与 $gJ$**（grill_equation_audit 审计发现）。
- 采用测压管水头 $H = p/(\rho g) + z$ 时，倾斜段重力已含于 $gA\,H_x$，MOC 中**再加 $gA\sin\theta$ 即重力双计**；若内部实现选压力变量 $p$，才显式写 $gA\,z_x$，并在接口层完成 $Q = AV$、$p = \rho g H$ 转换。
- 状态向量取 $[H,Q]$ 时特征阻抗 $Z_H = a/(gA)$（$\mathrm{s\,m^{-2}}$）；$Z_c = \rho a / A$（$\mathrm{Pa\,s\,m^{-3}}$）只能配 $p$–$Q$ 体系，**两套阻抗不得在传播矩阵中混用**。
- 一维长波近似有效域检查：$f_{sig} D / a \ll 1$（$f_{sig}$ 为用于推断的信号频率，非采样率）；不满足时须讨论径向模态/管壁动力学/流固耦合，而非仅减小步长。省略对流项的量级为 $V/a$，在 physics.yaml 中记录并在论文假设节声明。

### 2.2 MOC 相容式与 CFL 纪律

相容式必须写成含新时刻两个未知量的完整形式：

$$C^+:\; H_i^{n+1} + B\,Q_i^{n+1} = C_P, \qquad C^-:\; H_i^{n+1} - B\,Q_i^{n+1} = C_M, \qquad B = \frac{a}{gA}$$

（摩阻系数 $r = f\Delta x/(2gDA^2)$ 进入 $C_P, C_M$。）**漏掉 $\pm B\,Q_i^{n+1}$ 项会使两式矛盾且解不出新流量**——这是 wos_update_math_audit 中已发现的旧模块错误，新求解器以单元测试锁死。

$C_r = a\Delta t/\Delta x = 1$ 仅是特征线与均匀网格重合的相容取值；多段/多波速/非均匀网格必须用 $C_r < 1$ 插值、分段时间步或隐式处理，且须引 Ghidaoui & Karney (1994)：**插值数值弥散与高频反射波衰减同量级**，故正式实验以 $C_r \in \{0.8, 1.0\}$ 双档报告，凡涉及高频衰减率的结论均须给出两档差异。

### 2.3 簇节点方程（逐簇、逐孔、量纲显式）

每簇 $j$ 含 $m = 1..M_j$ 个射孔，节点闭合为 5 类方程联立：

$$\text{质量：} Q_j^- - Q_j^+ = \sum_m q_{jm} \qquad [\mathrm{m^3\,s^{-1}}]$$
$$\text{压力迹连续：} p_{w,j}^- = p_{w,j}^+ = p_{w,j} \qquad [\mathrm{Pa}]$$
$$\text{孔眼节流：} p_{w,j} - p_{in,jm} = K_{p,jm}\, q_{jm}|q_{jm}| + \kappa_{jm}\,\mathrm{sgn}(q_{jm})|q_{jm}|^{1/2}\text{（迂曲项，可选）}, \quad K_{p,jm} = \frac{\rho}{2 C_{d,jm}^2 A_{perf,jm}^2}$$

迂曲摩阻作为**独立加性项**给出，遵循压裂近井迂曲标准标度 $\Delta p_{tort} \propto q^{1/2}$，系数 $\kappa_{jm}$ 量纲 $\mathrm{Pa\,s^{1/2}\,m^{-3/2}}$；**禁止把迂曲项塞进 $K_p$ 内与 $\rho/(2C_d^2 A_{perf}^2)$ 混量纲相加**。若采用其他指数须给出依据并在 configs 中声明；该式配残差量纲单元测试（R1 触发器覆盖）。
$$\text{近井惯性/阻力：} p_{in,jm} - p_{c,jm} = I_{f,jm}\,\dot q_{jm} + R_{f,jm}\, q_{jm}$$
$$\text{裂缝储容/漏失：} C_{f,jm}\,\dot p_{c,jm} = q_{jm} - G_{l,jm}(p_{c,jm} - p_{res})$$

量纲：$C_f\,[\mathrm{m^3\,Pa^{-1}}]$、$I_f\,[\mathrm{Pa\,s^2\,m^{-3}}]$、$R_f\,[\mathrm{Pa\,s\,m^{-3}}]$、$G_l\,[\mathrm{m^3\,Pa^{-1}\,s^{-1}}]$。三条硬规则：
1. **RCI 拓扑一致性**：小信号端口阻抗为 $Z_b(s) = R_{perf} + R_f + sI_f + \dfrac{1}{sC_f + G_l}$，其中线性化 $R_{perf} = 2K_p|\bar q|$。储容支路是**并联** $Z_{C} = R/(1+sRC)$ 结构，不得误写为串联 $R + 1/(sC)$（grill_equation_audit）。稳态 $\bar q = 0$ 处 $R_{perf} = 0$ 但有限幅耗散仍为 $K_p|q|^3$，不能以零线性阻力否定孔眼非线性作用。
2. **漏失不重复扣除**：已进入储容 ODE 的 $q_l = G_l(p_c - p_{res})$ 不得再加到节点质量分流式。
3. **逐孔求和**：孔眼总面积只有同质同压降时才可合并；节点方程一律写 $\sum_m q_{jm}$，合并情形作为特例在 configs 中声明。

**正反演参数化分离（预注册硬规则）**：逐孔参数 $\{C_{d,jm}, A_{perf,jm}, R_{f,jm}, I_{f,jm}, C_{f,jm}, G_{l,jm}\}$ **仅用于正演数据生成**；反演目标一律预注册为**簇级等效量**——$\sum_m C_{d,jm} A_{perf,jm}$（孔眼等效流通量）、簇级 RCI 等效值（并联合成的 $C_{f,j} = \sum_m C_{f,jm}$、$G_{l,j} = \sum_m G_{l,jm}$，串并联合成的等效 $R_{f,j}, I_{f,j}$）与簇位置 $x_j$。该参数化写入 `configs/train_inverse.yaml` 并随 manifest 冻结，全部反演、FIM、profile likelihood 与 coverage 统计只在簇级等效量空间进行，**禁止事后回退到逐孔参数化重跑反演**（防止结果导向的参数化更改）；与 §5.3 的联合量降级规则（$C_d A_{perf}$ 乘积不拆分）逐级兼容。

旧模块的 `Cf [m²]`、`k_leak·sqrt(ΔH)` 参数**不得直接代入**，必须经单位标注适配器转换为上述 SI 参数，并配残差量纲单元测试。有效储容 $C_{eff}$ 与文献裂缝法向顺应性（$\mathrm{m\,Pa^{-1}}$）比较时须乘受压面积与几何系数。

### 2.4 频变摩阻：Zielke/Vardy–Brown 与 Brunone 的严格区分

**这是两类物理机制不同的模型，全文任何位置不得合并称为"非定常摩阻"。**

**（a）Zielke（层流）/ Vardy–Brown（湍流）频变卷积**（参考真值路径）：
$$J_{u,V}(t) = \frac{16\nu}{D^2} \int_0^t W\!\left(\frac{4\nu(t-s)}{D^2}\right) \dot V(s)\, ds$$
Zielke 权函数在大 $\tau$ 段（$\tau \gtrsim 0.02$）为 $W_Z(\theta) = \sum_n e^{-j_{2,n}^2 \theta}$（首根平方 $j_{2,1}^2 \approx 26.3744$）；**该指数级数仅为大 $\tau$ 展开，小 $\tau$ 段必须用 $\sqrt{\tau}$ 级数**——直接卷积参考实现须采用分段完整 $W$（小 $\tau$ 用 $\sqrt{\tau}$ 级数、大 $\tau$ 用指数级数），否则拟合下限取到 $10^{-8}$ 时参考真值本身在小 $\tau$ 处即错。卷积下限取零隐含扰动前充分发展稳态；**非稳态预历史须显式保留或以递归记忆状态 $z_l(0)$ 初始化**。直接卷积复杂度 $O(N_x N_t^2)$、内存 $O(N_x N_t)$，仅用于 goldens 与核拟合参考。

**（b）指数递归核**（生产路径，进入 MOC 与 CJ-NO）：
$$\dot z_l = -\beta_l z_l + \alpha_l \dot V, \qquad J_{u,V} = \sum_{l=1}^{M} w_l z_l, \quad M = 10$$
Vardy–Brown 权函数在 $\tau \in [10^{-8}, 10^2]$ 对数最小二乘拟合，且施加**显式正性约束 $w_l, \alpha_l, \beta_l > 0$**（无约束对数最小二乘可能拟出负 $w_l$，直接破坏 §2.6 被动性；该约束写入 friction_zielke.yaml 并配拟合后检查断言）。Vardy–Brown 湍流权函数含 Re 依赖的剪切衰减系数，**核参数不得取单套常数覆盖全 Sobol 采样域**：按 Re 分档拟合（或用 VB 缩放律参数化），分档表写入 friction_zielke.yaml，并在 A2 消融中报告 Re 敏感性。**验收线：核拟合相对误差 <2%，对基准波形直接卷积 vs 递归核相对 $L_2$ <1%、相位滞后 <1°**。复杂度降为 $O(N_x M N_t)$，但复杂度分析不能替代实测耗时——阶段一给出两路径 wall-clock 实测表。误差分解纪律：真实卷积误差、指数核截断误差、网络逼近误差**三者分开报告**，否则无法判断波形衰减来自物理还是代理。

**（c）Brunone 瞬时加速度模型**（对比分支）：采用标准形式 $J_{u} = k(V_t - a\,\mathrm{sgn}(V V_x)\,V_x)$ 类变体（**系数约定统一为 $k$，不用 $k/2$**，该约定锁定在 friction_brunone.yaml 并配特征值单元测试）。在 $\mathrm{sgn}(V V_x) = +1$ 分支将其并入主部得 $(1+k)V_t + gH_x - kaV_x + \cdots = 0$，常数 $k$ 下特征速度变为 $-a$ 与 $a/(1+k)$；**$\mathrm{sgn}(V V_x) = -1$ 分支对称地变为 $+a$ 与 $-a/(1+k)$，即特征修正随 $\mathrm{sgn}(V V_x)$ 在波前/驻点处逐点切换**。**特征结构已改变**，固定 $\pm a$ 模板必须配相应源项近似（滞后或局部迭代），或在离散矩阵中使用修正传播速度，且滞后/局部迭代近似须在 sgn 切换点单独验证——单管 Brunone golden 增设含流向反转的算例；并声明该结论仅对该具体变体成立。$k$ 系数与适用 Re 域写入 friction_brunone.yaml。

三种摩阻基准：稳态 Darcy、Zielke/VB（卷积与递归核两档）、Brunone，分别独立实现、独立验收、独立消融（A2）。

### 2.5 频率结构与观测带宽约束（设计性估计，非实测）

以典型算例 $L = 4000\,\mathrm{m}$、$a = 1400\,\mathrm{m/s}$、簇间距 $s = 15\,\mathrm{m}$：全井基波 $a/(4L) \approx 0.09\,\mathrm{Hz}$，簇间反射特征频率 $a/(2s) \approx 47\,\mathrm{Hz}$，两者相差约 3 个数量级——这是"高频簇信息 / 低频周期信息"分离的核心量级依据。数值分辨率核算（**按 $C_r = 1$ 计**）：$\Delta x = 4\,\mathrm{m}$ 时 $\Delta t \approx 2.86\,\mathrm{ms}$、Nyquist $\approx 175\,\mathrm{Hz}$（$C_r = 0.8$ 档相应 $\Delta t \approx 2.29\,\mathrm{ms}$、Nyquist $\approx 219\,\mathrm{Hz}$），须覆盖最小簇距 $s_{min} = 10\,\mathrm{m}$ 的反射带宽 $a/(2 s_{min}) \approx 70\,\mathrm{Hz}$。**有效带宽 $f_{eff}$ 的可计算定义**：观测链端到端传函 $-3\,\mathrm{dB}$ 点（备用核算：井口信号 PSD 能量 95% 分位频率），测定方法写入 data.yaml。观测链的 $f_s$、有效带宽 $B_{eff}$、抗混叠滤波与最小可辨簇距的关系式写入 data.yaml 并在论文观测模型节给出。回波定位线性误差传播 $\delta x \approx (a/2)\delta\tau + (\tau/2)\delta a$ 仅作直觉引导；未知波速、重叠回波与强滤波下不保证唯一解——这正是转向算子反演 + UQ 的动机表述。

### 2.6 能量收支闭合（被动性审计）

$$r_E = P_{ports} - \frac{dE_{tot}}{dt} - D_{wall} - D_{perf} - D_{frac} - D_{leak}$$

$E_{tot}$ 含井筒压缩势能/动能与裂缝 $C_f/I_f$ 储能；**记忆变量能量不计入 $E_{tot}$**——候选形式 $E_{mem} = \sum_l w_l z_l^2/(2\alpha_l)$ 的时间导数为 $J\dot V - \sum_l (w_l\beta_l/\alpha_l) z_l^2$，供给率与 $\dot V$ 配对，而非定常摩阻抽走的机械功率 $\propto \int \rho A\, J\, V\, dx$ 与 $V$ 配对，二者不配对，按该形式写进 $E_{tot}$ 无法闭合 $r_E$。改用**正实性论证**：$\alpha_l, w_l, \beta_l > 0$ 时记忆核传递函数满足 $\mathrm{Re}[H(j\omega)] = \sum_l w_l\alpha_l\omega^2/(\omega^2+\beta_l^2) \ge 0$，故 $-\int J\,V\,dt \ge 0$（在零初态、平方可积窗口意义下），非定常摩阻功率整体计入 $D_{wall}$。正性约束 $w_l,\alpha_l,\beta_l>0$ 在核拟合中强制（见 §2.4(b)）。若后续需要显式储能函数，可用 KYP 引理为 $(V, J)$ 配对构造含交叉项的储能函数，作为备选路径记录。有泵输入时不要求能量单调；**只有无外部输入的闭合被动窗口**才检查 $E(t+\Delta t) - E(t) \le 10^{-8}$（无量纲化后）。端口能量不平衡验收 $<10^{-4}$。

## 4. 阶段二：CJ-NO 结构保持正演算子（第 3–4 月）

### 4.1 架构

- **Cluster-set encoder**：可变簇数 + mask 的置换等变集合编码（DeepSets/attention），输出每簇 token（位置、$K_p$、RCI 参数嵌入）。
- **段传播算子 $\mathcal{P}_j$**：特征坐标 $(\xi^\pm = x \mp at)$ 下的 Fourier 层传播，每段独立参数化；**受 §2.4(b) 递归结构启发的可学习记忆通道**（$z_l$ 通道随波前传播）——注意 §2.4(b) 的递归 $\dot z_l = -\beta_l z_l + \alpha_l \dot V$ 是固定空间点上的时间递归，特征坐标下 $z_l$ 随波前平流时两族特征线交叉混合，与之"同构"并不显然，故不作"保证/同构"宣称；配套 pilot 单元测试：在无节点单管算例上冻结物理参数，比较网络记忆通道动力学与 MOC 记忆状态 $z_l(x,t)$ 的逐点误差（相对 $L_2 < 2\%$），列为 M3 验收项。
- **节点跳跃算子 $\mathcal{N}_j$（可微隐式 Newton 层）**：前向调用与 MOC 同一节点闭合方程组（§2.3）做阻尼 Newton；质量/压力迹连续采用**硬投影**（解析可满足的仿射约束层），孔眼/RCI 残差作为独立物理损失块。**梯度一致性三条硬承诺**：(1) 硬投影使原始全残差系统在约束流形上秩亏，IFT **必须写在消去仿射约束后的约减坐标系上**——先解析消去质量/压力迹约束得独立未知量 $\tilde u$ 与约减残差 $\tilde r$，再用 $\partial \tilde u^*/\partial \theta = -(\partial \tilde r/\partial \tilde u)^{-1} \partial \tilde r/\partial \theta$ 传梯度（直接对全残差求雅可比逆在数学上不成立）；并以 goldens 上的有限差分梯度校验（相对误差 $<10^{-4}$）作为 pilot 验收门（M3）。(2) 隐式层前向 Newton 与反向线性求解**强制 fp64**（fp32 下条件数 $10^6$ 以上梯度已不可信）；若采用混合精度须声明策略并给出梯度误差实测。(3) 落盘每 batch 的约减雅可比条件数分布，条件数 $>10^8$ 触发 Tikhonov 正则；正则化逆 $-(\tilde J+\lambda I)^{-1}\partial\tilde r/\partial\theta$ 给出有偏梯度，故除计数报告外，还须报告"含正则 batch 训练"与"剔除该类 batch 重训"的最终指标差异（或给出正则化梯度偏差上界与前向 Newton 容差 $10^{-8}$ 的耦合关系）。
- **Trunk 查询**：$(x, t, segment\_id, d(x, \Gamma_N))$ → 断片 $H, Q, z$ 与节点左右迹。

**关于 Gibbs/逼近下界的可证伪化**：不宣称"消除 Gibbs 振荡"或引用逼近下界作为定论；改为三个可测实验——(i) 节点邻域震荡能量 $\int_{|x-x_j|<2\Delta x} (u - \bar u)^2 dx$ 对比；(ii) 跳跃幅值误差 vs 训练样本量的标度曲线（CJ-NO vs FNO vs DeepONet）；(iii) OOD 簇位移下的相位误差退化率。理论论证仅作为动机放在方法节，措辞为"移动间断对全局基架构的已知逼近困难（引核验文献）促使我们采用域分解+显式跳跃参数化"。

### 4.2 损失与课程

无量纲 $L = L_{data} + L_{pde} + L_{bc} + L_{jump} + L_{memory} + L_{energy}$；$L_{jump}$ 逐簇含 $R_{mass}, R_{pressure}, R_{orifice}, R_C, R_I$。课程：data → PDE/jump → 长时窗 → memory → OOD 增广。**课程受控化三条纪律**：(1) 阶段切换判据预注册写入 train_forward.yaml——当前阶段损失块的验证残差连续 $k=5$ 个 epoch 相对下降 $<1\%$ 即切换，禁止事后调节；(2) 课程对**所有物理信息基线（PI-FNO / PI-DeepONet / cPINN）同等适用**，排除"增益来自训练协议而非架构"的替代解释；(3) 增设"无课程"对照臂（3 seeds），课程×权重策略组合实验计入 GPU·h 预算重核算（见 §8）。权重策略比较固定 / GradNorm / NTK 三分支并落盘梯度轨迹。

**公平性纪律**：所有基线共享 split、归一化、可比参数量（±20%）、训练预算（等 GPU·h 与等 epoch 双档）与 5 seeds（42–46）。另加两条防稻草人环节：(1) **超参搜索预算对等**——每方法等额 HPO 试验数（各 32 trials，同一搜索算法与可比搜索空间），HPO 日志随补充材料公开，禁止 CJ-NO 精调而基线只跑默认超参；(2) **输入表征对等**——所有基线共享同一 cluster-set encoder 作为条件化输入（基线 = encoder + FNO/DeepONet 主干），使对比严格落在传播与节点结构上；vanilla 输入版本若保留，则必须另列"encoder+FNO"一行，否则 H1 证据不成立。

## 5. 阶段三：可辨识性相图与两级反演（第 5–6 月）

### 5.1 观测模型（显式测量链）

$$y = M_\psi\, G(\theta, \eta; u_r) + \epsilon$$

$M_\psi$ 显式含采样、增益、传感器传函与滤波；$\eta$ 为妨害参数（波速、摩阻系数、传感器漂移）。反演一律在该观测模型下进行，禁止直接用干净仿真波形宣称现场适用性。

### 5.2 两级反演

1. **摊销逆编码器**（`encoder.py`）：从 $p_{head}(t)$ 输出簇数概率分布、排序后位置初值与参数后验初值（1D CNN + attention，输出置换对齐用排序或 Hungarian matching）。
2. **FIM 子空间投影精修**（`fim.py` + `projection.py`）：以 CJ-NO 为可微引擎，FIM 在 MAP 邻域、多起点、多 SNR 重算。**FIM 定义与谱约定（全文统一）**：$\mathrm{FIM} = J^\top \Sigma^{-1} J$，其中 $J = \partial y/\partial\theta$ 为观测对参数的灵敏度雅可比，$\Sigma$ 为观测噪声协方差——来源于 §5.1 测量链噪声模型（各 SNR 档下的加性噪声方差，独立同分布情形 $\Sigma = \sigma_n^2 I$；若含滤波引入的相关性则用滤波器传函推出的带状 $\Sigma$，写入 data.yaml）。**阈值作用谱明示**：工作阈值 $\sigma_i/\sigma_{max} > 10^{-3}$ 作用于**白化雅可比 $\Sigma^{-1/2}J$ 的奇异值**（等效雅可比条件数 $10^3$）；由于 FIM 特征值为该奇异值的平方，对应 FIM 特征值阈值为 $10^{-6}$、FIM 条件数 $10^6$——即 §5.3 的"条件数 $>10^6$ 安全阈值"与本节工作阈值实为**同一谱上的同一条线**（雅可比条件数 $10^3$ ⇔ FIM 条件数 $10^6$），全文引用条件数时必须标注所在谱（雅可比谱或 FIM 谱），禁止混报。**统一双阈值方案（换算到雅可比谱）**：工作阈值雅可比条件数 $10^3$ 定义可识别子空间；灰区上界（原"FIM 条件数 $10^6$"）即雅可比条件数 $10^3$，故原 $10^3$–$10^6$ 灰区重新表述为：雅可比谱 $\sigma_i/\sigma_{max} \in [10^{-3}, 10^{-1.5}]$ 内的方向标记为"弱可辨识"（给出估计值与显著加宽的可信区间，不进入强主张），$\sigma_i/\sigma_{max} < 10^{-3}$（FIM 条件数 $>10^6$）触发 §5.3 硬降级；H3 否证判据统一用雅可比条件数 $10^3$（见 §0.3）。**非 Gaussian 似然分支**：$\mathrm{FIM}=J^\top\Sigma^{-1}J$ 仅对 Gaussian 似然成立；Huber/Student-t 分支改用**观测信息阵**（负对数似然对 $\theta$ 的 Hessian，在 MAP 处以 Gauss–Newton 近似 $J^\top W(r) J$ 计算，$W(r)$ 为按残差加权的稳健权阵），两分支谱分析分开报告，禁止把 Gaussian-FIM 结论套用于稳健似然分支。仅在可识别子空间内 L-BFGS/adjoint 投影迭代。

**Profile likelihood 预注册协议**（区别于"似然切片"的硬规程）：对每个待评估参数 $\theta_k$，在其扫描格点上**逐格点对全部其余参数与妨害参数 $\eta$ 重新优化**（多起点 L-BFGS，收敛容差与起点数写入 configs）——固定其余参数只扫 $\theta_k$ 的做法是似然切片而非 profile，禁止混称。置信区间以似然比阈值判定：$\ell(\hat\theta) - \ell_p(\theta_k) \le \chi^2_{1,0.95}/2 \approx 1.92$（单参数 95% 档）。**边界触及判据**：若 95% profile 置信区间触及预注册扫描边界，该参数判为"实际不可辨识"（practically non-identifiable），不报点估计置信区间，转入 §5.3 联合量处理。每个参数的扫描范围（先验支撑内）与格点数（默认 $\ge 21$，对数或线性刻度按参数量纲声明）预注册写入 `configs/train_inverse.yaml`，禁止事后调整扫描窗口。

**代理灵敏度校验门**：FIM、profile likelihood 与可辨识性相图均以 CJ-NO 梯度计算，代理梯度误差会直接污染 FIM 谱与子空间判定（正演 $E_{L2}\le 5\%$ 不保证灵敏度误差 $\le 5\%$，OOD 区域尤甚）。故在 challenge case 子集（$\ge 20$ 例，覆盖相图各区域）上用 MOC 有限差分或伴随法计算参考灵敏度，报告与 CJ-NO 梯度的余弦相似度及 FIM 有效子空间主角（principal angles），验收阈值主角 $<10°$；不达标区域的相图格点标注为"代理不可信"而非"不可辨识"。

### 5.3 参数耦合病态的诚实处理（硬承诺）

若孔眼律只通过乘积 $C_d A_{perf}$ 进入观测，或该方向 FIM 条件数 $>10^6$（**FIM 谱**上的安全阈值，等价于 §5.2 白化雅可比谱条件数 $10^3$，与 §5.2 统一为同一条线；FIM 谱 $10^3$–$10^6$ 灰区即雅可比谱 $10^{1.5}$–$10^3$，按 §5.2 报告并标记"弱可辨识"）：**只报告联合量 $C_d A_{perf}$ / 等效端口导纳及其相关矩阵与可信区间，不分别报告 $C_d$ 与 $A_{perf}$**。同样处理 $R_f$–$G_l$、$C_f$–$I_f$ 的潜在耦合。反演参数空间本身已按 §2.3 预注册为簇级等效量（逐孔参数仅存在于正演数据生成端），本节联合量降级是在该簇级空间内的进一步收缩。论文明确声明：单点井口波形不宣称唯一解耦全部细观几何参数。

### 5.4 校准与抗噪矩阵

- **反 inverse crime 硬承诺（数据生成与反演端严格分离）**：全部 challenge case 真值波形用与反演端不同的正演配置生成——(i) 空间网格 2× 加密（取 §3.1 最细档），(ii) 不同 $C_r$ 档（真值 $C_r=0.8$、反演端代理以 $C_r=1$ 档数据训练，或反之，档位组合写入 manifest），(iii) 记忆核用**直接卷积路径**（分段完整 $W$，见 §2.4(a)）；反演端（CJ-NO 训练数据与 MOC 对照反演）一律只用指数递归核代理。真值生成配置与反演端配置的 (网格, $C_r$, 核路径) 三元组分离关系写入 challenge case manifest 并纳入 digest 校验；任一 challenge case 检出与训练/反演配置同源即触发 R13（见 §7），作废该 case 结果。
- challenge case 采样协议：**从先验独立抽样 $n \ge 200$ 例**（Owen-scrambled Sobol，与训练集 seed 不相交，manifest 冻结）× 5 噪声 seeds；SNR $\in \{\infty, 30, 20, 10, 5\}$ dB + 1–3% 脉冲野值；Gaussian 与 Huber/Student-t 似然并列。
- 以小规模 MCMC/SMC 做后验金标准，校验摊销+投影后验的 coverage 与 CRPS/NLL。
- **Coverage 统计协议（预注册）**：coverage 在上条 $n \ge 200$ 例先验独立抽样上计算**全局 coverage**（frequentist-over-prior 意义），并按 §5.4 相图区域（可辨识 / 弱可辨识 / 不可辨识区）**分层报告**各层 coverage 与层内样本数；另补 **SBC（simulation-based calibration）rank 统计**（每例记录真值在后验样本中的秩，检验 rank 直方图均匀性，报告 $\chi^2$ 检验 p 值）作为独立校准证据。**明示口径**：主报告的 95% coverage 为**逐参数边际** credible interval 的覆盖率（逐参数分别报告），联合（最高后验密度域）coverage 作为补充表单列。**抽样不确定度**：$n = 200$ 时 coverage 估计的二项抽样 95% CI 约 $\pm 3\%$（如观测 0.95 时 Wilson 区间约 $[0.911, 0.973]$），全部 coverage 数值须随附二项 CI，判定 §5.5 的 $[0.90, 0.98]$ 门时以 CI 与目标区间的关系（CI 完全在内/相交/完全在外）三态报告，禁止只报点值。
- 可辨识性临界相图实验设计：在 $(s_{min}/\lambda_{eff},\ \mathrm{SNR},\ N)$ 三轴网格上扫描 F1 与位置 MAPE，绘制可辨识/不可辨识分界（Fig_5）。

### 5.5 量化验收门与降级规则

| 指标 | 目标 |
|---|---|
| 参数 MAPE（ID / OOD） | $\le 10\%$ / $\le 20\%$（仅对 FIM 可识别联合量） |
| SNR = 10 dB 时 MAPE 增幅 | $\le 50\%$ |
| 95% coverage | $0.90$–$0.98$ |
| 簇数 F1 | $\ge 0.90$ |
| 位置误差 | 报告分布 + 与 $s_{min}$ 之比 |
| CRPS / NLL / 后验相关矩阵 | 报告 |

## 6. 阶段四：基线消融、盲测与论文总装（第 7–8 月）

### 6.1 基线矩阵（纯数据与物理信息分列）

### 6.3 盲测与外部有效性

冻结 OOD manifest hash 后**只运行一次**盲测。**模型选择预注册硬规则**：checkpoint 选择仅依据 ID 验证集 early-stopping（规则写入 train_forward.yaml 并随 manifest 冻结），禁止在 ID-test 或 OOD 上挑 checkpoint/挑 seed 后再盲测；盲测报告全部 5 seeds 的均值±SD 与最差 seed，禁止 best-seed 单报。至少一个未参与训练的实验或现场测量链（含波速、采样、滤波、摩阻、边界的全链校准）作外部验证；无法获得时在局限节明确声明并降级外推主张。

### 6.4 速度核算

$$M_{\text{break-even}} = \frac{T_{label} + T_{train}}{T_{MOC} - T_{infer}}, \quad \text{要求 } T_{MOC} > T_{infer}$$

审计节律：审计命令分两档——**CPU 全流程 smoke 档**：`python run_all_reproducible.py --stage k --seed 42 --device cpu --smoke`（缩减样本/epoch，逐阶段走通全链路，供审稿人与 CI 快速核验）；**GPU 全量复现档**：`python run_all_reproducible.py --stage k --seed 42 --device cuda --full`（复现论文全部数字）。GPU 档强制确定性标志：`torch.use_deterministic_algorithms(True)`、`cudnn.deterministic=True`、`cudnn.benchmark=False`、关闭 TF32（`allow_tf32=False`），标志写入 environment.lock 随附说明；**跨硬件复现容差声明**：同 seed 跨 GPU 型号（如 A100 vs 4090）的最终指标偏差须 $<0.1\%$（相对），超差须在 README 声明具体硬件依赖来源。两档均可从 manifest 恢复任一阶段；每月 tag 含 MOC 版本、配置、manifest、指标 JSON、图表脚本、失败清单、environment.lock；正式盲测前两名内部审阅者逐条核对"主张—证据路径—数值门槛—统计区间—局限性"。

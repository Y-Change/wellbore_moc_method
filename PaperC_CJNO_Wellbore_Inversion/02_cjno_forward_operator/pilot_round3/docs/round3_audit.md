## 2. 8 案失败：哪些替代原因被排除，哪些仍未排除？

| 替代原因 | 本轮结论 |
|---|---|
| 主要是优化预算/调度太短 | **支持、且是主因**：B1 在 step≈200 仍 ≈0.14（对齐 Round2），step 700 已 ≤2%，5000 step mean=0.0045。stop=`step_budget`，不是收敛声明。 |
| 主要是共享尺度 MSE 压错幅值 | **排除为唯一主因**：B2 也过门（0.0061）。权重有影响但不是「不过门」的必要原因。 |
| 随机种子不稳 | **本预算内未支持**：预先登记 seed 43 的 B1 仍 PASS（0.0041）。 |
| 指标把失败算进成功均值 | A 已修；B 选模用扰动 L2，不受相位 coverage=0 污染。 |
| 归一化 dtype/常数维 | 已修并重训；不是用旧 ckpt 重评分。 |
| 架构不可能拟合这 8 条井口扰动 | **本预算内排除**（过门）。不外推到 64/256。 |
| 查询 8 s 截断一个 4L/a | **未排除**对相位/更难指标的影响；L2 门不依赖完整周期。 |
| 未消费 I_f/R_f/G_l/κ/p_res/粗糙度/TVD/逐孔/初态 | **未排除**对 64 案或物理泛化的影响；本 8 案井口 L2 不需要它们也能过门。 |
| 缺少节点损失 / 需要段传播学习 | **未排除**为物理闭环所必需；对这 8 案井口头过拟合不是必需。 |

单例拟合：**未跑**（仅两臂都未过门时才启动）。

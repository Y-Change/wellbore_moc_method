### 阻塞 A — 往返 2x/a（pilot_00543）

- 事实：单程已过；往返观测 7.13445 s，期望 `t_s+2x/a=7.12410` s，误差 0.01035 s，门 0.00930 s。

### 阻塞 B — Cf 光滑点梯度门

- 事实：K 全步长 rel = 1.59e-5 / 4.84e-5 / 1.16e-3，最佳过 1e-4（保留全部步长）。Gl 最佳 8.91e-6 过门。ZVB 上 K 三步长均 <1e-4。Cf 相对扰动 `g_auto=-502.44`，FD rel = 4.86e-3 / 1.0 / 1.0（小步 FD 崩到 0）。
- **最便宜实验：** 对 Cf0 改用与 K 相同的**绝对**中心差分（`eps = 1e-3/1e-4/1e-5 * |Cf0|`），同一 302 步窗口、同一 `ProductionMOC`。若最佳仍 ≥1e-4，再查 IFT 对 `C_f` 的 `∂r/∂θ`；不要先换方程。

- `max_iter=0` 时原 `solve_cluster_node` 返回 `ok=False`（rinf=2.33），`TrainEntry` 不推进 optimizer / scheduler / `global_step`，动态状态未污染。`max_iter=1` 仍收敛。正常 `max_iter=100` 下本案 302 步失败率 0。这只验证处理路径，不是分布失败率。

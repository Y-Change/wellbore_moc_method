## 1. 阶段研发背景与核心破局点 (Executive Summary)

在第一阶段（Phase 1）预研中，三大基准模型（1D-ResNet、1D-FNO、Vanilla DeepONet）与原型网络（CJ-Cep-DeepONet）确立了水击波反演的物理可行性，证明了 Voronoi 空间守恒池化的数学完备性（单纯形守恒偏差 $< 1.8 \times 10^{-7}$），并在单簇（$N_c=1$）工况下达成卓越指标（$\alpha$ MAE 严格为 $0.000$，$C_f$ MRE 达到 $9.38\% \sim 11.92\%$，$W_1 = 0.00\,\mathrm{m}$）。

然而，面对密集多簇（$N_c=2\sim 6$，簇间距 $\Delta x \in [5, 40]\,\mathrm{m}$）的实际压裂工况，井口单点观测面临严重物理瓶颈：
1. **回波时差极小**：相邻两簇的双程声学反射时延差仅为 $\Delta \tau = 2\Delta x / a \approx 6.9 \sim 55.2\,\mathrm{ms}$；
2. **频域严重混叠**：多反射波相干叠加产生破坏性干涉，井口宏观压力衰减包络呈现多解性，单通道 Fisher 信息阵（FIM）呈现近奇异性；
3. **全局池化缺陷**：第一阶段模型采用全时程全局池化，不同深度的激波起跳相位混乱，导致 $\alpha$ $R^2$ 停滞在 $0.41 \sim 0.51$。

针对上述瓶颈，第二阶段正式实施并完整构建了 **TG-CJ-DeepONet (Time-Gated Characteristic-Jump Deep Operator Network)** 物理反演主干网络。核心创新机制包括：
1. **多模态物理到时对齐提取（Time-Gating）**：依托管柱声速 $a$ 与已知几何坐标 $x_j$，显式求解波前回波理论往返到时 $\tau_j = t_s + 2x_j/a$，在时域截取并可微重采样归一化，实现物理波前严格对齐至 $t=0$；
2. **声学时延偏置簇间解耦注意力（Acoustic-Biased Decoupling Transformer）**：在簇间自注意力中显式注入声学传播距离物理惩罚偏置 $\mathbf{B}_{ij} = -\gamma \frac{|x_i - x_j|}{a}$（$\gamma \ge 0$），强制抑制跨空间远距虚假相关，聚焦解耦局部干涉；
3. **双轨协同解码头（Dual-Track Collaborative Heads）**：轨 1（离散精准头）经 Masked Softmax 严格保证 $\sum \hat{\alpha}_j = 1.0$ 与对数顺应性预测；轨 2（连续场辅助头）解码全井密度场 $\hat{m}_\alpha(x)$ 与 $\hat{c}_H(x)$ 并经 Voronoi 守恒积分；双轨通过一致性损失 $\mathcal{L}_{cons} = \sum |\hat{\alpha}_j - \int_{\Omega_j} \hat{m}_\alpha(x) dx|$ 达成物理自洽协同。

### 2.1 理论往返到时计算
对于射孔簇 $j$（井口已知完井深度 $x_j$），关泵水击脉冲在井筒内以声速 $a$ 传播，其首波到达该簇并反射回井口的总时间为：
$$\tau_j = t_s + \frac{2 x_j}{a}$$
其中：
- $t_s = 1.0\,\mathrm{s}$ 为关泵动作时刻；
- $a = \mathrm{cond}[1] \times 20.0 + 1450.0\,\mathrm{m/s}$ 为实测有效声速；
- $x_j$ 为已知射孔簇深度。

### 2.2 三大物理到时窗提取机制（支持一键消融切换）
1. **模式 1 (`relative_window`, 旗舰机制)**：
   在时域截取每簇局部回波窗口 $[\tau_j - 50\,\mathrm{ms}, \tau_j + 250\,\mathrm{ms}]$（总窗长 $300\,\mathrm{ms}$），利用可微一维重采样（`F.grid_sample`）归一化至固定点数 $N_w = 128$ 点。该变换使所有簇的首波到达严格对齐在 $t=0$（即重采样窗内的第 $50\,\mathrm{ms}$ 处），彻底抹平各簇因绝对深度差异造成的时差漂移；
2. **模式 2 (`gaussian_gating`)**：
   在全时程波形 $H(t)$（$N_t=4096$ 点）上直接施加可微软高斯加权窗：
   $$w_j(t) = \exp\left(-\frac{(t - \tau_j)^2}{2\sigma_j^2}\right)$$
   其中窗宽 $\sigma_j > 0$ 设置为可学习参数（初始化为 $80\,\mathrm{ms}$），经 1D 卷积抽取各簇门控波形特征；
3. **模式 3 (`ceps_patch`)**：
   将时域波形与空间反射倒谱融合构建 2D 连续时空能量底图 $S(t, x)$（$N_t \times N_x$），在每簇对应的理论时空中心 $(\tau_j, x_j)$ 处提取局部大小为 $16 \times 16$ 的图块（Patch），经 2D 卷积与自适应池化映射为簇表征。

### 2.3 声学时延偏置簇间解耦注意力
多头自注意力得分矩阵显式融入两簇间的双程声学传播时差：
$$\mathbf{A}_{ij} = \mathrm{Softmax}\left(\frac{\mathbf{q}_i \mathbf{k}_j^T}{\sqrt{d}} - \gamma \frac{|x_i - x_j|}{a}\right)$$
- $\gamma = \mathrm{Softplus}(\theta_\gamma) \ge 0$ 为可学习的非负物理距离衰减惩罚系数；
- $|x_i - x_j| / a$ 为簇 $i$ 与簇 $j$ 之间的声学传播单程时差；
- 距离越远的簇，其相互注意力受到越强的物理惩罚，网络自然聚焦于邻近产生强波前干涉的临近簇，从而彻底消除由于全局自注意力引起的远距虚假相关。

### 2.4 双轨协同头与一致性损失
- **轨 1（离散精准头）**：由 Transformer 解耦特征 $\mathbf{h}_j$ 经 MLP 产生未归一化 logits $z_j$，经 Masked Softmax 输出：
  $$\hat{\alpha}_j = \frac{\exp(z_j)}{\sum_{k \in \mathcal{C}_{valid}} \exp(z_k)}, \quad \forall j \in \mathcal{C}_{valid}$$
  未激活簇严格赋 0，数学上严格保证 $\sum_{j=1}^{N_c} \hat{\alpha}_j = 1.0$；
  同时直接回归对数水力顺应性 $\log_{10}(\hat{C}_{f,j} / C_{f,0})$；
- **轨 2（连续场辅助头）**：井筒全局特征 $\mathbf{z}_{well}$ 与 Trunk 网络空间高频傅里叶基点乘，输出全井连续密度场 $\hat{m}_\alpha(x)$ 与顺应性场 $\hat{c}_H(x)$，经可微 Voronoi 空间守恒池化输出区间积分量 $\hat{\alpha}_j^{field} = \int_{\Omega_j} \hat{m}_\alpha(x) dx$；
- **双轨协同损失函数**：
  $$\mathcal{L} = \lambda_\alpha \mathcal{L}_{KL} + \lambda_c \mathcal{L}_{Huber} + \lambda_W \mathcal{L}_{W_1} + \lambda_{cons} \mathcal{L}_{cons}$$
  其中 $\mathcal{L}_{cons} = \frac{1}{N_c} \sum_{j=1}^{N_c} |\hat{\alpha}_j - \hat{\alpha}_j^{field}|$。

## 4. 关键科学发现与消融机理解读 (Scientific Insights & Skepticism)

### 4.1 物理到时对齐的决定性增益
从全局实验数据可以明确看到：
1. **$R^2$ 跃升至 0.5666**：第一阶段 CJ-Cep-DeepONet 由于采用整波池化与全局外积，反演决定系数仅为 $R^2 = 0.4148$；在消除 $6\times$ 物理时间尺度失准并引入精确波前对齐后，$R^2$ 大幅跃升至 **$0.5666$**，相比 Phase 1 提升幅度超 **$36.6\%$**；
2. **声学时延偏置的物理赋能**：在声学惩罚系数参数化对齐水击脉冲特征频度（$\gamma \approx 10.0\,\mathrm{s}^{-1}$）后，声学偏置自注意力（`TG-Rel-Bias`）相较无偏置消融组（`TG-Rel-NoBias`）在各指标上全面占优（$\alpha$ MAE 从 0.1449 降至 0.1336，降幅 7.8%；$R^2$ 提升 0.0302；$W_1$ 从 9.20m 缩减至 8.39m，降幅 8.8%）；
3. **空间等效距离 $W_1$ 达成全局最优 8.39m**：在 $N_c=3$ 复杂多波干涉工况下，$W_1$ 达到 $6.04\,\mathrm{m}$，相较第一阶段原型 CJ-Cep（$11.91\,\mathrm{m}$）实现腰斩。

### 4.2 三大多模态窗机制的性能分层
- **相对窗机制 (`relative_window`) 表现最佳**：其通过可微插值将每簇波前起跳严格锁定在相对窗口第 50ms 处，局部 1D 卷积核可以直接学习波前斜率与首波反射幅度，彻底消除了卷积位置不变性的空间漂移负担；
- **高斯软窗机制 (`gaussian_gating`)**：通过连续门控精确聚焦回波（初始化 80ms 高斯软窗），表现优于全局池化模型，但由于全时程波形时间轴未做波前起跳归一化，网络仍需在全波形上拟合不同深度簇的起跳形态；
- **倒谱切片图块 (`ceps_patch`)**：在修正时空网格转置缺陷后，局部图块可准确抽取 $(\tau_j, x_j)$ 邻域时空能量，指标稳定达到 $\alpha$ MAE = 0.1449。

### 4.3 客观反思与残留局限 (Skepticism & Root Causes)
尽管第二阶段在密集簇群的局部解耦与相关性上有显著突破，但仍需客观指出以下科学局限：
- **$C_f$ 顺应性在多簇下的相对误差仍约 46%**：这是由于井口单通道压力信号具有物理不可逆性——微小顺应性变化引发的波形幅值衰减，极易被沿程摩阻与管壁弹性效应吸收掩盖。单纯依靠纯数据驱动在单通道下将 $C_f$ 误差压至 15% 以下极其困难，**必须在第三阶段引入 MOC 可微前向物理正演求解器构成自校正闭环**；
- **800 个训练样本对 6 簇参数空间的覆盖度有限**：6 簇同时变化的自由度极高（$6 \times 2 = 12$ 维连续空间），增加训练样本量或引入等效阻抗桥梁将是后续工作的重要方向。

# 倒谱裂缝检测器技术介绍

本文档描述水击波倒谱分析中的 **三条裂缝检测器**。它们共用同一张二维倒谱响应图，只在检测层不同。文档按“可迁移到其他项目”编写：给出输入约定、算法步骤、公式、默认超参、输出字段与适用场景，不依赖本仓库的目录结构。

源码参考（本仓库）：

- `benchmark/methods/cepstrum_2d.py`
- `benchmark/methods/common.py`

三条检测器：

| 名称 | 入口函数 | 检测函数 | 核心思想 |
|------|----------|----------|----------|
| 1D 聚合检测 | `run_cepstrum_1d` | `detect_fractures` | 时间轴压缩成 1D 深度曲线，再拾峰 |
| 2D 持久性检测 | `run_cepstrum_2d` | `detect_fractures_2d` | 逐帧拾峰，用跨帧出现比例筛真峰 |
| 链式 Beam Search | `run_cepstrum_chain` | `detect_fractures_chain` | 锚点 + 间距先验向外扩展，专攻深层弱簇 |

---

## 0. 共用输入：二维倒谱响应

检测器不直接吃原始压力时序，而是吃已经完成倒谱变换后的深度–时间图。

### 0.1 物理背景

井口压力可近似写成源波子与稀疏反射序列的卷积：

\[
p(t)=w(t)*\sum_k r_k\,\delta(t-\tau_k),\qquad \tau_k=\frac{2d_k}{v}
\]

其中 \(d_k\) 为裂缝深度，\(v\) 为波速，\(\tau_k\) 为双程走时。实倒谱把卷积变成加法，周期性回波在倒频率轴 \(q\) 上表现为尖峰，同时会产生谐波与交叉项：

\[
C(q)\approx C_w(q)+\sum_k r_k\,\delta(q-\tau_k)+\sum_{i,j} r_i r_j\,\delta\bigl(q-|\tau_i\pm\tau_j|\bigr)
\]

深度映射：

\[
d=q\cdot\frac{v}{2}
\]

### 0.2 检测器实际使用的张量

底层函数 `compute_cepstrum_1d()` 输出：

| 字段 | 形状 | 含义 |
|------|------|------|
| `depth` | `(N_d,)` | 深度轴，单位 m |
| `response_2d` | `(N_d, N_t)` | 取负后的倒谱响应 \(R_{2D}(d,t)=-C(q,t)\)，裂缝反射为正峰 |
| `response` | `(N_d,)` | 沿时间轴聚合后的 1D 深度曲线（仅 1D 检测器使用） |
| `t_cep` | `(N_t,)` | 倒谱帧中心时间，单位 s |
| `q` | `(N_d,)` | 对应倒频率，单位 s |

约定：

- 裂缝反射对应 **正峰**。后续所有 `find_peaks` 的高度 / 突出度阈值都 clamp 到 \(\ge 0\)，负值噪声不进峰检测。
- 深度分辨率由采样率与波速决定，与窗长无关：

\[
\Delta d=\frac{v}{2f_s}
\]

典型值 \(v=1200\,\mathrm{m/s}\)、\(f_s=1000\,\mathrm{Hz}\) 时，\(\Delta d=0.5\,\mathrm{m}\)。
- 深度上限 `depth_max` 一般取井筒长度。
- 谐波分析下限：

\[
d_{\min}=d_{\max}\cdot r_{\min}
\]

默认 \(r_{\min}=0.5\)，即只对井深下半段做谐波/鬼影抑制。浅层强反射不惩罚。

### 0.3 其他项目最小接入方式

只要能提供 `depth` 与 `response_2d`（以及 1D 路径所需的 `response`），就可以单独移植三条检测器，不必移植整套倒谱前端。若没有现成 1D 曲线，可用第 1 节的时间轴聚合从 `response_2d` 生成。

## 1. 检测器 A：1D 聚合峰拾取（`cepstrum_1d`）

### 1.1 适用场景

- 需要一条可解释的深度响应曲线。
- 信号较干净，或只关心强反射。
- 作为 2D 方法的对照基线。

局限：时间维被压掉后，偶发交叉项与持续真峰混在同一条曲线上，虚警通常高于 2D 持久性法。

### 1.2 流程

```text
response_2d(d, t)
        │
        ├─ 取后段稳定窗（默认后 60% 帧）
        ├─ 沿时间轴聚合 → response(d)
        ├─ find_peaks（高度 / 突出度 / 最小间距）
        ├─ 置信度 = 峰高 / 全局最大
        ├─ 计算谐波惩罚 H(d)（抑制前快照）
        └─ 可选：谐波抑制并按调整得分重排
```

### 1.3 时间轴聚合

函数：`aggregate_time_axis(data_2d, mode, stable_ratio)`

先取稳定窗，再压缩。设总帧数为 \(T\)，稳定比例为 \(\rho\)（1D 入口默认 \(\rho=0.6\)）：

\[
t_0=\bigl\lfloor T(1-\rho)\bigr\rfloor,\qquad
R_{\mathrm{stable}}(d,\cdot)=R_{2D}(d,\,t_0{:}T)
\]

| `mode` | 公式 | 用途 |
|--------|------|------|
| `percentile90`（默认） | \(r(d)=\mathrm{P}_{90}\bigl(R_{\mathrm{stable}}(d,\cdot)\bigr)\) | 保留强反射，抑制偶发尖刺 |
| `median_mad` | \(r(d)=\mathrm{med}+3\cdot\mathrm{MAD}\) | 更稳健的上包络 |
| `max` | \(r(d)=\max_t R_{\mathrm{stable}}\) | 最敏感，虚警最多 |
| `mean` | \(r(d)=\mathrm{mean}_t R_{\mathrm{stable}}\) | 最平滑，弱峰易被抹掉 |

`MAD` 使用正态一致性尺度（`scipy.stats.median_abs_deviation(..., scale='normal')`）。

### 1.4 1D 峰拾取

函数：`detect_peaks(depth, response, ...)`

1. 裁剪到 \(d\le d_{\max}\)。若有效点数 \(<2\)，或峰谷差 \(<10^{-12}\)，返回空。
2. 把最小间距从米换成 bin：

\[
\Delta d=\mathrm{median}(\Delta\mathrm{depth}),\qquad
n_{\mathrm{dist}}=\max\bigl(1,\lfloor d_{\mathrm{gap}}/\Delta d\rfloor\bigr)
\]

3. 正值百分位阈值：

\[
h=\max\bigl(\mathrm{P}_{h\%}(r),\,0\bigr),\qquad
p=\max\bigl(\mathrm{P}_{p\%}(r),\,0\bigr)
\]

4. `scipy.signal.find_peaks(r, height=h, prominence=p, distance=n_dist)`
5. 置信度：

\[
s_i=\frac{r(d_i)}{\max r}
\]

6. 按峰高降序，最多保留 `max_peaks` 个。

### 1.5 默认超参

| 参数 | 默认 | 说明 |
|------|------|------|
| `aggregate_mode` | `percentile90` | 时间聚合 |
| `stable_ratio` | `0.6`（入口） | 稳定窗占后段比例；底层函数默认 0.5 |
| `height_pct` | 85 | 高度百分位 |
| `prominence_pct` | 80 | 突出度百分位（`detect_peaks` 默认） |
| `min_distance_m` | 5.0 | 比 2D 更保守，近间距缝更容易并峰 |
| `max_peaks` | 10 | 最多返回峰数 |
| `depth_min_ratio` | 0.5 | 谐波抑制起始深度比 |
| `suppress_harmonics` | True | 见第 4 节 |

### 1.6 输出

| 字段 | 含义 |
|------|------|
| `positions` | 候选深度 (m) |
| `scores` | 抑制后置信度（相对峰高） |
| `response` | 1D 深度曲线 |
| `harmonic_penalty` | 全深度 \(H(d)\)，抑制前快照 |
| `n_detected` | 峰个数 |

## 2. 检测器 B：2D 持久性检测（`cepstrum_2d`）

这是主方法。核心假设：**真裂缝反射在多个时间帧里反复出现；噪声和交叉项是偶发的。**

### 2.1 适用场景

- 默认裂缝定位流水线。
- 需要同时压虚警、保定位精度。
- 可输出持久性曲线 \(P(d)\) 与谐波惩罚 \(H(d)\)，适合作为后续模型通道。

局限：深层弱峰可能在多数帧里达不到百分位阈值，\(P(d)\) 掉到 `min_persistence` 以下被丢掉。这是链式检测器要补的缺口。

### 2.2 流程

```text
response_2d(d, t)
        │
        ├─ 裁剪 d ≤ depth_max
        ├─ 对每一时间帧独立 find_peaks
        ├─ 统计每个深度 bin 的跨帧出现比例 P(d)
        ├─ 丢掉 P(d) < min_persistence 的峰
        ├─ score = P(d) × 该深度在出现帧上的平均强度
        ├─ 按 score 取 top-K
        ├─ 计算 H(d)（抑制前快照）
        └─ 可选：谐波抑制并重排
```

### 2.3 逐帧峰检测

函数：`_detect_peaks_2d`

对每一帧 \(t=1,\dots,T\)，令 \(c(d)=R_{2D}(d,t)\)：

\[
h_t=\max\bigl(\mathrm{P}_{85}(c),\,0\bigr),\qquad
p_t=\max\bigl(\mathrm{P}_{80}(c),\,0\bigr)
\]

\[
\mathcal{P}_t=\mathrm{find\_peaks}\bigl(c;\;\mathrm{height}=h_t,\;\mathrm{prominence}=p_t,\;\mathrm{distance}=n_{\mathrm{dist}}\bigr)
\]

返回的是 **深度 bin 索引列表**，不是插值后的亚网格深度。因此同一物理峰必须落在同一 bin 才会累计持久性。\(\Delta d=0.5\,\mathrm{m}\) 时，通常可以接受；若其他项目网格更粗，需要先把邻近 bin 聚类再统计。

### 2.4 持久性与综合评分

函数：`_score_2d_persistence`

指示函数：

\[
\mathbb{1}_t(d)=\begin{cases}
1,& d\in\mathcal{P}_t\\
0,& \text{otherwise}
\end{cases}
\]

持久性：

\[
P(d)=\frac{1}{T}\sum_{t=1}^{T}\mathbb{1}_t(d)\in[0,1]
\]

过滤：

\[
\mathcal{D}_{\mathrm{cand}}=\bigl\{d:P(d)\ge p_{\min}\bigr\}
\]

出现帧集合 \(\mathcal{T}_d=\{t:d\in\mathcal{P}_t\}\)，平均强度与综合分：

\[
\bar R(d)=\frac{1}{|\mathcal{T}_d|}\sum_{t\in\mathcal{T}_d}R_{2D}(d,t),\qquad
S(d)=P(d)\cdot\bar R(d)
\]

按 \(S(d)\) 降序取前 `max_peaks` 个。\(P(d)<p_{\min}\) 的位置仍保留在持久性向量里，只是不进入候选列表。

经验：`min_persistence=0.62` 曾把 Precision 从约 0.32 提到约 0.46，同时 Recall 会下降。主入口默认 `0.6`；底层函数默认 `0.5`。迁移时建议在目标数据上扫描 \(0.45\sim 0.70\)。

### 2.5 为什么有效

倒谱交叉项 \(\delta(q-|\tau_i\pm\tau_j|)\) 依赖两路反射同时进入同一分析窗，且相位要对齐，因此在时间轴上不稳定。真裂缝对应固定双程走时，只要窗内还看得到该周期，峰就会反复出现。持久性等于无监督置信度，不需要裂缝条数先验。

### 2.6 默认超参

| 参数 | 入口默认 | 底层默认 | 说明 |
|------|----------|----------|------|
| `height_pct` | 85 | 85 | 逐帧高度百分位 |
| `prominence_pct` | 80 | 80 | 逐帧突出度百分位 |
| `min_distance_m` | 3.0 | 3.0 | 允许较近裂缝（1D 为 5 m） |
| `min_persistence` | 0.6 | 0.5 | 跨帧出现比例下限 |
| `max_peaks` | 10 | 10 | 最多返回峰数 |
| `depth_min_ratio` | 0.5 | — | 谐波抑制起始深度比 |
| `suppress_harmonics` | True | True | 见第 4 节 |
| `lifter` | False | True（仅 `compute_cepstrum_1d`） | 高通提升；检测入口关闭 |

注意：`run_cepstrum_2d(..., lifter=False)` 会覆盖底层倒谱计算的 lifter 默认值。历史上半余弦提升窗会连同浅层裂缝一起压掉，F1 明显下降，因此检测流水线默认关闭。

### 2.7 输出

| 字段 | 形状 | 含义 |
|------|------|------|
| `positions` | `(K,)` | 候选深度 |
| `scores` | `(K,)` | \(S(d)\) 经谐波抑制后的分数 |
| `response_2d` | `(N_d, N_t)` | 原倒谱图 |
| `persistence` | `(N_d,)` | 全深度 \(P(d)\) |
| `harmonic_penalty` | `(N_d,)` | 全深度 \(H(d)\) |
| `n_detected` | 标量 | 峰个数 |

## 3. 检测器 C：链式 Beam Search（`cepstrum_chain`）

针对 **深层紧簇 + 后缝弱 + 2D 持久性漏检**。本数据上真裂缝常以 5–20 m 间距成簇出现；2D 方法用全局同一套百分位阈值，深层弱峰很难跨过 `min_persistence`。

### 3.1 适用场景

- 已知或近似已知裂缝成簇、间距有上下界。
- 2D 方法 Precision 尚可，但深层 Recall 不足。
- 可选：裂缝条数已知（`count_mode='known'`）。

不要用的情况：裂缝沿井筒均匀稀疏、间距没有簇结构，或浅层孤立单缝。间距先验会把远离锚点的真峰当成“非同簇”丢掉。

### 3.2 流程

```text
response_2d(d, t)
        │
        ├─ 限制在 [depth_min, depth_max]
        ├─ 逐深度估计 signal / noise / SNR / persistence
        ├─ 在 signal 曲线上用较低阈值生成候选峰（宁滥勿缺）
        ├─ 高持久性候选作为锚点（多种子）
        ├─ Beam Search：每轮向当前链加入满足间距窗的候选
        │     评分 = 持久性为主 + SNR 居中软加权
        │     过近/过远/鬼影 分别惩罚或直接拒绝
        ├─ auto：取累计分最高的链（长度可变）
        │  known：在长度为已知条数的链中取最高分
        └─ 对最终峰计算 H(d)（仅记录，不再改分数）
```

链式法 **不** 在检测后再做 `_suppress_harmonics` 乘性降权。鬼影在扩展时用硬门控扣分；`H(d)` 只作为解释/下游特征。

### 3.3 深度域特征

函数：`_compute_chain_features`

全部在目标段 \([d_{\min}, d_{\max}]\) 上计算。对每个深度：

\[
s(d)=\mathrm{P}_{90}\bigl(R_{2D}(d,\cdot)\bigr)
\]

\[
n(d)=\mathrm{median}_t R_{2D}(d,\cdot)+k\cdot\mathrm{MAD}_t\bigl(R_{2D}(d,\cdot)\bigr),\quad k=3
\]

\[
\mathrm{SNR}_{\mathrm{dB}}(d)=10\log_{10}\frac{\max(s(d),\varepsilon)}{\max(n(d),\varepsilon)}
\]

\(\varepsilon=\max(10^{-3}\max s,\,10^{-12})\)，防止非物理极值。

持久性 \(P(d)\) 的计算方式与 2D 检测器相同（逐帧 `find_peaks`，高度 p85、突出度 p80），但 **这里不设 `min_persistence` 硬阈值**，只把 \(P(d)\) 当作软特征。

候选峰在 \(s(d)\) 上用更低阈值生成：

\[
h_{\mathrm{cand}}=\max\bigl(\mathrm{P}_{60}(s),\,\varepsilon\bigr)
\]

若一个候选都没有，退化为 \(\arg\max s(d)\)。原则是宁滥勿缺，后续靠间距、鬼影和评分淘汰。

### 3.4 候选评分

SNR 居中基准取候选集合的中位数：

\[
\mathrm{SNR}_{\mathrm{ref}}=\mathrm{median}\{\mathrm{SNR}_{\mathrm{dB}}(d_i):i\in\mathrm{cand}\}
\]

\[
\mathrm{cscore}(i)=w_P\bigl(P_i-P_{\mathrm{member}}\bigr)+w_S\bigl(\mathrm{SNR}_{\mathrm{dB}}(i)-\mathrm{SNR}_{\mathrm{ref}}\bigr)
\]

默认 \(w_P=10\)，\(w_S=1\)，\(P_{\mathrm{member}}=0.55\)。

设计意图：

- 持久性仍是主判别。真峰跨帧稳定，噪声偶发。
- SNR 只做相对加权。用逐深度噪声基底归一化后，深层弱峰可以和浅层强峰比相对突出度，而不是比绝对能量。
- 减去 \(P_{\mathrm{member}}\) 与 \(\mathrm{SNR}_{\mathrm{ref}}\) 后，噪声候选的分数接近 0 或为负。向链里加入弱噪声会拉低累计分，这就是 `auto` 模式能自动停的原因。

### 3.5 鬼影门控

函数内部 `is_ghost(cidx, chain)`。候选深度 \(d_c\) 相对 **当前链已有成员** \(\{d_i\}\)：

- 谐波：\(d_c\approx 2d_i\) 或 \(3d_i\)
- 交叉项：\(d_c\approx d_i+d_j\) 或 \(|d_i-d_j|\)
- 相对误差容差默认 8%
- 组合深度须 \(>1\,\mathrm{m}\)

命中则本步加分再减 `ghost_penalty`（默认 50）。这是软拒绝：分被大幅扣掉，通常进不了 beam，但不是直接从候选表删除。

与第 4 节全局谐波抑制的差别：链式门控只看 **当前部分链**，并且谐波倍数只检查 2、3 倍，不检查 4–10 倍。

### 3.6 Beam Search

1. **锚点**：\(P(i)\ge P_{\mathrm{anchor}}\)（默认 0.6）的候选。若没有，退化为 `cscore` 最高的 1 个。取 top `n_seeds`（默认 5）作为多种子。
2. 初始 beam：每个锚点自成一条链，分为该锚点的 `cscore`。
3. 最多扩展 `max_peaks-1` 轮。对 beam 中每条链、每个未入链候选：
   - \(P(c)<P_{\mathrm{member}}\)：跳过
   - 与链内最近成员的间距 \(g\)
     - \(g < d_{\mathrm{gap}}\)（默认 3 m）：视为重复，跳过
     - \(g > s_{\max}\)（默认 30 m）：超出簇连续性，跳过
     - \(s_{\min}\le g\le s_{\max}\)：正常加入
     - \(d_{\mathrm{gap}}\le g < s_{\min}\)：仍可加入，但扣间距惩罚
   - 加分：

\[
\Delta = \mathrm{cscore}(c)
-\mathbb{1}[g<s_{\min}]\cdot\lambda_s\cdot\frac{s_{\min}-g}{s_{\min}}
-\mathbb{1}[\mathrm{ghost}]\cdot\lambda_g
\]

默认 \(\lambda_s=5\)，\(\lambda_g=50\)。
4. 新链按成员深度排序后去重，保留分数最高的 `beam_width` 条（默认 5）。
5. 所有历史假设（含较短的中间链）都进入终选池。

数量策略：

| `count_mode` | 行为 |
|--------------|------|
| `auto` | 在全部历史链中取累计分最高者，长度可变 |
| `known` | 优先取长度等于 `num_fractures` 的最高分链；没有则取不超过该数目的最长链中的最优者 |

最终成员按 `cscore` 降序输出。对外分数为 \(\max(\mathrm{cscore},0)+10^{-6}\)，保证非负。

多种子 + beam 是为了避免纯贪心“第一个锚点错了，整条链全错”。

### 3.7 默认超参

| 参数 | 默认 | 说明 |
|------|------|------|
| `depth_min_ratio` | 0.5 | 只在井深下半段搜簇 |
| `min_distance_m` | 3.0 | 重复峰下限 |
| `spacing_min_m` | 3.0 | 簇内间距先验下界 |
| `spacing_max_m` | 30.0 | 簇内间距先验上界 |
| `p_min_anchor` | 0.6 | 锚点持久性 |
| `p_min_member` | 0.55 | 成员持久性（低于 2D 的 0.62，用来回收深层弱峰） |
| `persist_weight` | 10.0 | 持久性权重 |
| `snr_weight` | 1.0 | SNR 软权重 |
| `ghost_tol` | 0.08 | 鬼影相对误差 |
| `ghost_penalty` | 50.0 | 鬼影扣分 |
| `spacing_penalty` | 5.0 | 间距偏短扣分 |

| `n_seeds` | 5 | 锚点种子数 |
| `max_peaks` | 6 | 链最大长度 |
| `count_mode` | `auto` | `auto` / `known` |
| `cand_height_pct` | 60 | 候选生成百分位 |
| `mad_k` | 3.0 | 噪声基底 MAD 倍数 |
| `suppress_harmonics` | True | 仅控制扩展时的鬼影门控 |

间距窗必须按目标数据改。本数据裂缝间距约 5–20 m，所以 \(s_{\max}=30\)。若另一项目裂缝间距是 50–100 m，不改这个参数会把真峰全部判成“超出簇”。

### 3.8 输出

| 字段 | 含义 |
|------|------|
| `positions` / `scores` | 最终链成员及非负评分 |
| `persistence` | 全深度 \(P(d)\)（段外为 0） |
| `harmonic_penalty` | 最终峰的 \(H(d)\) |
| `snr_db_segment` / `depth_segment` | 目标段 SNR 曲线 |
| `trace`（可选） | 锚点、扩展顺序、每个候选的接受/拒绝原因 |

`return_trace=True` 时，候选原因包括：

| `reason` | 含义 |
|----------|------|
| `accepted` | 进入最终链 |
| `reject_low_persistence` | \(P < P_{\mathrm{member}}\) |
| `reject_spacing_far` | 距当前簇过远 |
| `reject_too_close` | 与已有成员过近 |
| `reject_ghost` | 谐波/交叉项门控 |
| `reject_low_score` | 通过硬约束但累计分未胜出 |

## 4. 共用后处理：谐波 / 交叉项抑制

1D 与 2D 检测器在出峰之后调用；链式检测器只计算 \(H(d)\)，分数改动改由第 3.5 节门控完成。

倒谱对数非线性会在整数倍走时与和差组合处制造鬼影。抑制只拿 **更强的峰** 去解释 **更弱的峰**，最强峰永远视为干净。

### 4.1 乘性降权 `_suppress_harmonics`

输入：`positions`、`scores`。按 score 降序扫描。仅处理 \(d_i\ge d_{\min}\) 的峰。

**谐波**（\(k=2,\dots,10\)）：

\[
\frac{d_i}{d_j}\approx k,\qquad
\frac{|d_i/d_j-k|}{k}<\eta=0.08
\quad\Rightarrow\quad
s_i\leftarrow 0.3\,s_i
\]

**交叉项**：

\[
d_i\approx d_j\pm d_k,\qquad
\frac{|d_i-(d_j\pm d_k)|}{|d_j\pm d_k|}<\eta
\quad\Rightarrow\quad
s_i\leftarrow 0.5\,s_i
\]

交叉项组合深度须 \(>1\,\mathrm{m}\)。同一弱峰可被多次命中，权重连乘。之后按新分数重排，位置集合不变。

### 4.2 全深度惩罚图 `compute_harmonic_penalty`

输出 \(H(d)\in\{0.3,0.5,1.0\}^{N_d}\)。非峰位置为 1.0。

- 谐波命中：\(H=0.3\)
- 交叉项命中：\(H=\min(H,0.5)\)
- 两种都命中时取更严惩罚（先写 0.3，交叉项不会把 0.3 抬回去）

\(H(d)\) 在抑制 **之前** 计算，记录的是原始峰关系，不是降权后的排序结果。可直接作为下游模型通道。

## 5. 三条检测器对照

| 项目 | 1D 聚合 | 2D 持久性 | 链式 Beam Search |
|------|---------|-----------|------------------|
| 输入 | `response(d)` | `response_2d(d,t)` | `response_2d(d,t)` |
| 时间信息 | 聚合后丢掉 | 用 \(P(d)\) 显式保留 | \(P(d)\) + 逐深度 SNR |
| 真假峰判据 | 峰高 / 突出度 | 跨帧稳定性 | 稳定性 + 相对 SNR + 间距先验 |
| 裂缝条数 | 阈值 + top-K | 阈值 + top-K | `auto` 用累计分停，或锁定已知条数 |
| 近间距 | 默认 5 m，易并峰 | 默认 3 m | 3 m 去重，3–30 m 成簇 |
| 深层弱峰 | 易被浅层强峰阈值淹没 | 全局同一 `min_persistence`，易漏 | 降低成员阈值 + SNR 居中 |
| 鬼影 | 检测后乘性降权 | 同左 | 扩展时门控扣分 |
| 需要的先验 | 几乎无 | 几乎无 | 需要簇间距窗 |
| 推荐角色 | 基线 / 可视化 | 主检测 | 深层漏检补救 |

选择建议：

1. 先上 2D 持久性，作为默认检测器。
2. 虚警多：提高 `min_persistence`，打开谐波抑制。
3. 深层漏检、且裂缝确实成簇：再上链式检测，按实际间距改 `spacing_max_m`。
4. 1D 聚合只作为对照，或给需要单通道深度曲线的模型用。

### 6.1 最小函数集


依赖：`numpy`、`scipy.signal.find_peaks`、`scipy.stats.median_abs_deviation`。链式特征用 `collections.Counter` 以外无额外包。

### 6.2 必须一并带走的约定

1. `response_2d` 已经取负，峰为正。
2. 所有高度 / 突出度阈值 `max(percentile, 0)`。
3. 持久性按 **相同深度 bin 索引** 计数，不做亚网格聚类。
4. `depth_min` 控制谐波分析范围，不是检测盲区；1D/2D 仍会报告浅层峰。链式检测则把搜索限制在 \([d_{\min},d_{\max}]\)。
5. 2D 入口 `min_persistence=0.6` 与底层默认 `0.5` 不同；移植时不要混用。
6. 链式 `spacing_max_m` 是数据相关先验，换项目必须重标定。

### 6.3 建议评估协议

与真值做贪心最近邻一对一匹配，默认容差 5 m，输出 Precision / Recall / F1 / MAE。空预测时 Precision=Recall=0；空真值时 Recall=1、Precision=0。

### 6.4 调参顺序

1. 确认 `depth` 轴与波速映射正确（\(\Delta d=v/(2f_s)\)）。
2. 画 `response_2d`，确认真裂缝是跨帧竖条，而不是随机散点。
3. 扫 `min_persistence`，优先看 Precision–Recall 权衡。
4. 若近缝合并，把 `min_distance_m` 从 5 降到 3。
5. 若深层漏检且有簇结构，再开链式检测并扫 `spacing_max_m`、`p_min_member`。
6. 谐波抑制的 8% 容差一般可先不动；若真缝恰好接近 2 倍关系，应收紧容差或提高 `depth_min`。

## 7. 伪代码汇总

### 7.1 2D 持久性

```text
frame_peaks ← []
for t in 1..T:
    h ← max(percentile(R[:,t], 85), 0)
    p ← max(percentile(R[:,t], 80), 0)
    frame_peaks[t] ← find_peaks(R[:,t], height=h, prominence=p, distance=n_dist)

count[d] ← 0
for t, peaks in frame_peaks:
    for d in peaks:
        count[d] ← count[d] + 1

P[d] ← count[d] / T
candidates ← {d : P[d] ≥ p_min}
S[d] ← P[d] * mean(R[d, t] for t where d in frame_peaks[t])
positions ← top_k(candidates by S)
H ← harmonic_penalty(positions, S)
if suppress:
    S ← suppress_harmonics(positions, S)
    reorder by S
```

### 7.2 链式 Beam Search

```text
feat ← signal, noise, SNR, P, cand   # 均在 [d_min, d_max]
cscore(i) ← 10*(P[i]-0.55) + 1*(SNR[i]-median_SNR_cand)
anchors ← top n_seeds of {i in cand : P[i] ≥ 0.6}
beam ← [([a], cscore(a)) for a in anchors]
finished ← copy(beam)

repeat max_peaks-1 times:
    hyps ← []
    for (chain, score) in beam:
        for c in cand \ chain:
            if P[c] < 0.55: continue
            g ← min |d[c]-d[k]| for k in chain
            if g < min_distance or g > spacing_max: continue
            Δ ← cscore(c)
            if g < spacing_min: Δ ← Δ - spacing_penalty * (spacing_min-g)/spacing_min
            if is_ghost(c, chain): Δ ← Δ - ghost_penalty
            hyps.append(sorted(chain+[c]), score+Δ)
    if hyps empty: break
    beam ← top beam_width unique hyps
    finished.extend(beam)

if known_count:
    pick best chain with len == known_count (else closest not exceeding)
else:
    pick max-score chain in finished
```

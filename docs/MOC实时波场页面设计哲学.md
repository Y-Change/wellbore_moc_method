# 深井脉冲

页面以深井内的瞬态波作为唯一叙事对象。界面不模拟控制台的繁复，也不把科研过程拆成无关的小组件；它让两条并列的、持续生长的压力云图成为视觉中心，如同两张同步展开的地层记录。每一处留白、网格线与时间刻度都服务于波前的识别。

色彩以近黑的井下环境承载数据，冷青表示稳态达西路径，烧赭表示 Brunone 路径；共同的高亮黄只用于当前计算时刻和停泵事件。色彩不是装饰，而是模型身份与时间定位的精确编码。图面经过细致校准，应像资深研究人员长期使用的实验仪器，而不是通用数据看板。

版式以“左侧设定、中央观测、底部验证”组织。左栏安静收纳最少的物理输入；中央两幅同尺度云图允许目光瞬间比较传播、反射与衰减；底部仅保留井口压力曲线，把空间场与实验可观测量直接相连。每条轴、每个数值标签和每段间距都必须经由严谨而耐心的推敲。

实时性应以连续生长的时间—井深图来表达：每积累一个显示批次，就在云图右侧追加一列，并同步延长井口曲线。页面不等待完整求解后再播放，也不插入倒谱、裂缝节点或模型差值等旁支内容。最终效果应是精雕细作、具备大师级克制的科研观察窗口，让用户在计算进行时就看见两种摩阻如何塑造整段井筒中的压力波。

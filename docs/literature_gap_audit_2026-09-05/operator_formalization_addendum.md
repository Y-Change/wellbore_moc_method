# 算子形式化、界面损失与稀疏反演判据补充

**用途与证据边界。** 本附录补足主报告中尚未完全展开的数学定义，服务于后续方法设计和可复现实验。FNO（Li 等，2020/2021）、DeepONet（Lu 等，2021）、PI-DeepONet（Wang 等，2021）、PINO（Li 等，2024）、CPINN（Jagtap 等，2020）和 clawNO（Liu 等，2024）分别提供了算子逼近、物理残差或守恒编码的先例；下文把它们与井筒–多簇裂缝边界组合起来的形式是**本报告的研究设计建议**，不是声称任何一篇前人论文已经实现。

## 1. 从参数函数到观测函数的算子

令井筒区间为 `Omega=(0,L)`，状态为

`u=(H,Q,z_1,...,z_M)`，

其中 `H` 为压力水头，`Q` 为流量，`z_l(x,t)` 为将历史摩阻核压缩成指数记忆状态的辅助变量。参数输入写成

`mu=(a,D,A,f,{x_j, N_{p,j}, C_{d,j}, C_{f,j}, R_{f,j}, I_{f,j}}_{j=1}^{N_c}, q_in(t), q_out(t))`。

这里 `{x_j}` 是界面拓扑/位置，不能默认为光滑参数场。正演解算子和井口观测算子分别定义为

`G: mu -> u|_{Omega x (0,T)}`，

`S: mu -> y(t)=H(0,t)+epsilon(t)`，`epsilon~N(0,Sigma)`。

对固定拓扑、固定参数空间，`G` 可在选定函数拓扑中讨论连续性；当簇位置移动或阻抗对比趋于奇异时，必须把位置编码（例如 level-set/indicator 通道）作为输入，并单独验证跨拓扑误差。不能直接把连续算子逼近定理当作变位置跳跃问题的保证。

## 2. FNO 与 DeepONet 的明确表达

一个二维时空 FNO（也可在时间窗上作因果滚动）可写成

`v_0=P(mu_grid)`，

`v_{r+1}(xi)=sigma(W_r v_r(xi)+F^{-1}[ R_r(k) F(v_r)(k) ](xi))`，

`u_hat=Q(v_R)`。

`F` 是离散 Fourier 变换，`R_r(k)` 只保留 `|k|<=k_max` 的复矩阵。对内部簇，建议输入三类通道：平滑物性、界面 indicator `chi_j(x)=1_{x>=x_j}` 的差分/level-set，以及簇参数 token；同时报告 `k_max` 改变时的反射峰、相位和守恒误差。Fourier 截断导致的误差只能由实验或基准计算测量，不能先验断言必然发生 Gibbs 失效。

DeepONet 的函数到点表示为

`G_hat(mu)(xi)=sum_{r=1}^p b_r( mu(s_1),...,mu(s_m) ) t_r(xi)`。

`b_r`（branch）编码参数/边界采样，`t_r`（trunk）编码查询位置和时间。对于变数量簇，可让 branch 同时接收带 mask 的集合 token；但 mask 只解决输入表示，不自动满足节点守恒。PINO/PI-DeepONet 的 PDE 残差应在解码后的物理量上计算，并将界面残差从体积分点中分离出来。

## 3. 可计算的界面与耗散损失

在第 `j` 个簇，定义左、右井筒极限和各裂缝支路流量 `Q_j^-`,`Q_j^+`,`q_{j,m}`。建议的无量纲界面损失为

`r_mass,j = (Q_j^- - Q_j^+ - sum_m q_{j,m}-q_leak,j)/Q_ref`，

`r_press,j,m = (p_w,j-p_in,j,m-Delta p_perf,j,m-Delta p_nw,j,m)/p_ref`，

`r_perf,j,m = [Delta p_perf,j,m-rho q_{j,m}|q_{j,m}|/(2 C_{d,j,m}^2 A_{perf,j,m}^2)]/p_ref`。

若采用集总裂缝储容/惯性，另设

`r_C,j = [C_{f,j} dot(p_c,j)-q_j+q_l,j]/q_ref`，

`r_I,j = [p_in,j-p_c,j-I_{f,j} dot(q_j)-R_{f,j}q_j]/p_ref`，

其中 `p_in` 是射孔/近井损失之后的裂缝入口压力，`p_c` 是储容状态压力，且
`q_l,j=G_{l,j}(p_c,j-p_res)`。因此节点和射孔损失应以 `p_w-p_in` 闭合，储容和漏失则以 `p_c` 闭合；不能把 `p_in`、`p_c` 合并为一个压力变量。

主井筒压力连续可写 `r_H,j=(H_j^- - H_j^+)/H_ref`；它不等于射孔两侧压力相等。多孔眼只有同压降、同系数时才可先合并面积，否则必须逐孔计算再求和。

将体残差、边界残差和界面残差组合为

`L_phys = L_PDE + lambda_J sum_j(||r_mass,j||_2^2+||r_press,j||_2^2+sum_m||r_perf,j,m||_2^2) + lambda_RC sum_j(||r_C,j||_2^2+||r_I,j||_2^2)`。

为避免网络把物理耗散误学成数值衰减，可增加离散功率平衡检验，而不把它假定为自动满足。相对于静止参考状态，建议写成

`E_tot=E_wb+sum_j[1/2 C_{f,j}(p_c,j-p_res)^2+1/2 I_{f,j}q_j^2]+E_mem`，

并检验

`P_in(t)=dE_tot/dt+D_wall+D_perf+D_nw+D_frac+D_leak`。

`E_mem` 由所采用历史摩阻的被动状态实现确定；`C_f>=0`、`I_f>=0`、`G_l>=0`、`R_f>=0` 是该检验的参数条件。`D_wall,D_perf,D_nw,D_frac,D_leak` 分别是壁面摩阻、孔眼二次损失、近井损失、裂缝阻力和漏失耗散，其中 `D_frac=sum_j R_f,j q_j^2`，均应按具体离散实现计算，且不能重复计入同一近井损失。围绕静止参考构造上述能量，在无外部输入、参数常定且所有闭合被动的窗口，才可推出 `E_tot` 非增；初始扰动可以非零。有泵压输入或非被动的学习记忆状态时，不应强制场能量单调。上述功率平衡是建议的验收约束，离散稳定性和严格误差界仍需单独证明或数值试验。

Zielke 型记忆项可用递归近似表示为 `dot z_l=-beta_l z_l+alpha_l dot V`、`J_u=sum_l w_l z_l`。这是对卷积的可微实现建议；`alpha_l,beta_l,w_l` 应由选定 Reynolds 数和拟合误差标定，不能把 Brunone 瞬时项与该记忆状态混为同一模型。训练时应分别做“无摩阻、已知摩阻、未知摩阻”消融，以分离网络相位/振幅偏差和真实物理耗散。

## 4. 单点井口反演的可辨识性判据

设待反演向量 `theta` 包含可辨识的参数组合（例如位置、总孔眼面积、等效 `R/C/I`），观测为 `y=S(theta)+epsilon`。在给定基准 `theta_0` 处，灵敏度矩阵为

`J_{nk}=partial y(t_n;theta)/partial theta_k`，

加权 Fisher 信息矩阵为

`F=J^T Sigma^{-1}J`。

若 `rank(F)<dim(theta)`，至少存在局部一阶不可辨识方向；很小的奇异值对应局部噪声放大方向。对于等效闭合 `d(2 N_f h_f l_f w_f)/dt=Q-Q_leak`，在 `h_f,w_f` 和漏失固定时，储容对 `N_f l_f` 存在一个等效变换方向。这只能证明该局部化简模型的结构相关性，不能单凭此式推出完整非线性、多工况模型的全局非唯一性。应结合 profile likelihood、全局扫描、FIM 条件数或后验相关矩阵，并将“可辨识参数组合”和“只能给等效量”分开。

对候选泵停机激励 `u_r(t)`，可用 `det(F_r)`、最小奇异值或 D-optimal 设计选择多工况；验证集必须包含未见簇位置、射孔方案、摩阻系数和噪声水平。逆算子输出应给出 `p(theta|y)` 或置信区间覆盖率，不能只用压力 RMSE 证明结构参数被恢复。上述 FNO/DeepONet 加界面损失、FIM 诊断和后验输出的联合方案，是待验证的研究假设，也是可辩护的研究缺口表述。

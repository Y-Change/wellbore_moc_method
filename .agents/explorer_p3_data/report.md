#### 关键预处理映射数学表达：
1. **波形降采样与一阶差分通道**：
   - 原始时程包含 60,001 个离散点（采样率 $f_s = 1000\,\mathrm{Hz}$，历时 $60.0\,\mathrm{s}$）；
   - 全局等距抽取 4,096 点，有效采样间隔 $\Delta t_{down} \approx 0.01465\,\mathrm{s}$（等效采样率 $f_{s, down} \approx 68.27\,\mathrm{Hz}$，奈奎斯特截止频率 $34.13\,\mathrm{Hz}$）；
   - 通道 0 执行每样本去均值除方差归一化：$y_0(t) = [H(t) - \mu_H] / (\sigma_H + 10^{-6})$；
   - 通道 1 提取一阶差分并按方差缩放：$y_1(t) = \Delta y_0(t) / (\sigma_{\Delta y_0} + 10^{-6})$。
2. **同态倒谱空间网格插值**：
   - 基于实测水头时程与理论声速 $a$，通过同态变换（实倒谱）将时间延迟 $\tau$ 转换为空间深度 $x = a \tau / 2$；
   - 线性插值映射至 $0 \sim 5000\,\mathrm{m}$ 的 1024 点固定空间网格（网格分辨率 $\Delta x \approx 4.888\,\mathrm{m}$），并消除直流偏置与方差标准化。
3. **工况特征向量归一化**：
   - 关泵历时 $t_c \in [0.001, 0.100]\,\mathrm{s} \implies \mathrm{cond}[0] = (t_c - 0.05) / 0.03$；
   - 井筒声速 $a \in [1420, 1480]\,\mathrm{m/s} \implies \mathrm{cond}[1] = (a - 1450) / 20.0$；
   - 远场孔隙水头 $H_{ext} \in [80, 120]\,\mathrm{m} \implies \mathrm{cond}[2] = (H_{ext} - 100) / 15.0$。
4. **高斯连续进液密度场**：
   - 在空间查询网格 $x \in [0, 5000]\,\mathrm{m}$（500 点，$\Delta x = 10.02\,\mathrm{m}$）上构造混合高斯场：
     $$m_\alpha(x) = \sum_{j=1}^{N_c} \alpha_j \frac{1}{\sqrt{2\pi}\sigma} \exp\left(-\frac{(x - x_j)^2}{2\sigma^2}\right), \quad \sigma = 20.0\,\mathrm{m}$$
   - 黎曼积分强制归一化：$\int_0^L m_\alpha(x) dx = 1.0$，为 Wasserstein 距离提供物理监督。

### 3.2 高斯白噪声与有色粉红噪声生成原理

#### A. 加性高斯白噪声 (Additive White Gaussian Noise, AWGN)
对标准化单样本水头波形 $y(t) \in \mathbb{R}^{N_t}$（$N_t=4096$），其有效动态能量定义为方差：
$$P_{sig} = \frac{1}{N_t} \sum_{i=1}^{N_t} (y_i - \bar{y})^2$$
给定目标信噪比 $\mathrm{SNR}_{\mathrm{dB}} \in \{30, 20, 10\}$，噪声方差与标准差为：
$$P_{noise} = \frac{P_{sig}}{10^{\mathrm{SNR}_{\mathrm{dB}} / 10}}, \quad \sigma_{noise} = \sqrt{P_{noise}}$$
输入双通道波形在时域直接加噪：
$$\tilde{y}_0(t) = y_0(t) + \mathcal{N}(0, \sigma_{noise}^2), \quad \tilde{y}_1(t) = \frac{\Delta \tilde{y}_0(t)}{\sigma_{\Delta \tilde{y}_0} + 10^{-6}}$$

#### B. 有色粉红噪声 (Colored / Pink $1/f$ Noise)
模拟井下复杂地层吸水压力蠕变、低频流体紊动与地面注水泵源周期性脉动。粉红噪声功率谱密度正比于 $1/f$（幅度衰减正比于 $1/\sqrt{f}$）。
生成算法：
1. 在频域生成白噪声傅里叶变换：$X(f) = \mathcal{F}\{\mathcal{N}(0, 1)\}$；
2. 施加 $1/\sqrt{f}$ 频域滤波：$Y(f) = X(f) \cdot f^{-0.5}$（零频直流分量置 0）；
3. 逆傅里叶变换得时域粉红序列：$w_{pink}(t) = \mathrm{Re}(\mathcal{F}^{-1}\{Y(f)\})$；
4. 归一化去均值并将方差重缩放至 $\sigma_{noise}^2$。

### 3.3 声速扰动 ($\pm 1\%$) 的物理机制与致命时延冲击

现场水平井由于压裂液砂比变化、管壁微变形及温度梯度，实际流体声速往往偏离 nominal 设计值约 $\pm 1\%$（$\Delta a = \pm 14.5\,\mathrm{m/s}$）。
对于完井深度 $x_j \approx 4500\,\mathrm{m}$ 的深部簇，回波理论往返时延 $\tau_j = t_s + 2x_j/a$ 的漂移量为：
$$\Delta \tau_j = 2 x_j \left(\frac{1}{a(1 \pm 0.01)} - \frac{1}{a}\right) \approx \mp \frac{2 \times 4500}{1450} \times 0.01 = \mp 62.07\,\mathrm{ms}$$
**当前相对到时窗机制的致命缺陷剖析**：
Phase 2 最优网络 `tg_relative_bias` 采用以理论到时 $\tau_j$ 为中心的相对时间窗：
$$[\tau_j - 50\,\mathrm{ms}, \tau_j + 250\,\mathrm{ms}]$$
其前向提取严重依赖“波前在相对窗口第 50ms 处起跳”的强先验：
- **当声速估计偏大 $+1\%$ 时**：实际回波到达时间为 $\tau_{true} = \tau_{est} + 62.1\,\mathrm{ms}$。在截取窗口内，波前起跳点漂移至第 $112.1\,\mathrm{ms}$ 处，彻底打乱了局部卷积核的对齐基准；
- **当声速估计偏小 $-1\%$ 时**：实际回波到达时间为 $\tau_{true} = \tau_{est} - 62.1\,\mathrm{ms}$。实际波前起跳发生在窗口起始时间（$\tau_{est} - 50\,\mathrm{ms}$）之前 $12.1\,\mathrm{ms}$，导致**最关键的首波起跳陡度在窗口截取时被完全切除丢弃**！

| 粉红噪声 SNR 10dB | 0.1490 | +11.5% | 0.4887 | -13.7% | 9.26 m | 49.9% | 强噪声鲁棒 |
| **声速扰动 -1%** | 0.1502 | +12.5% | 0.4660 | -17.7% | 9.46 m | 49.8% | 边缘受损 |
| **声速扰动 +1%** | **0.2111** | **+58.0%** | **-0.0950** | **-116.8%** | **15.58 m** | **82.5%** | **FAIL (严重崩溃)** |

#### 深度科学论断：
1. **加性高斯白噪声与粉红噪声完全达标**：在 20dB 噪声干扰下，指标衰减仅为 6%~10%，不仅远低于 15% 门槛，且即使在 10dB 极端恶劣噪声下，MAE 恶化亦控制在 12% 以内；
2. **纯信号到时截取机制具有致命硬脆性**：声速仅 $+1\%$ 的偏差便造成决定系数由 0.5666 跌落为负值（$-0.0950$）。**这在实验层面上确立了 Phase 3 的核心攻关方向：必须建立与局部截取窗脱钩的传递矩阵可微逆散射层剥离算子**。

### 5.3 深度机理解构：为什么密集多簇 $R^2$ 仅有 0.1319？

在测试集上分别对稀疏样本（$N_c \in [1, 3]$，53 例）与密集样本（$N_c \in [4, 6]$，47 例）执行分层隔离评估，揭示出以下深层机理：

```
====================================================================================================
分层对比:              全集样本 (100例)       稀疏簇群 (Nc in 1..3, 53例)    密集簇群 (Nc in 4..6, 47例)
模型名称               alpha MAE / R^2        alpha MAE / R^2               alpha MAE / R^2
====================================================================================================
1D-ResNet              0.1449 / 0.5072        0.1822 / 0.4888               0.1284 / 0.0340
1D-FNO                 0.1449 / 0.5072        0.1822 / 0.4889               0.1284 / 0.0340
CJ-Cep-DeepONet        0.1548 / 0.4148        0.1972 / 0.3782               0.1360 / -0.1211
TG-DeepONet (旗舰)     0.1336 / 0.5666        0.1596 / 0.5609               0.1220 / 0.1319
====================================================================================================
```

#### 关键力学与声学根源：
1. **多径串扰与透射扼流 (Acoustic Transmission Choking & Multi-path Cross-talk)**：
   关泵产生的水击压力波在经过每个裂缝簇时，由于孔眼截面突变与裂缝顺应性，均会发生显著的波阻抗失配（部分反射、部分透射）。跟部第 1 簇不仅反射能量，而且急剧衰减向下游传播的入射波能；深部第 4~6 簇的反射波在向井口返回过程中，又必须逆向穿透上游所有裂缝，经历多重二次反射与非定常摩阻剪切耗散。井口接收到的信号已高度混叠，失去单调因果性。
2. **均方差损失函数下的“均值退化陷阱” (Mean-Seeking Bias in Multi-Cluster Space)**：
   由于网络前端未进行物理透射衰减补偿与多径解混，无法解析下游微弱回波。在反向传播优化（MSE 或 KL 散度）驱动下，网络为最小化期望风险，最稳妥的策略是直接输出各簇的先验均值（$\hat{\alpha}_j \approx 1 / N_c \approx 0.16 \sim 0.25$）。
3. **密集簇群自身方差较小的数学倍率效应**：
   在 5~6 簇密集工况下，由于单纯形约束 $\sum \alpha = 1.0$，真实流量份额的离差平方和 $SS_{tot} = \sum (\alpha - \bar{\alpha})^2$ 本身非常微小。当网络输出趋向常数均值时，残差平方和 $SS_{res} \approx SS_{tot}$，直接导致 $R^2 = 1 - SS_{res} / SS_{tot}$ 趋近于 0，在第一阶段基准模型中甚至退化为严重负值（$-0.1211$）。

## 6. 对 Phase 3 架构演进与研发的直接建议 (Actionable Recommendations)

基于本专题调查与实验实测，提出以下三项直接支撑 Phase 3 顺利达标的核心工程建议：

### 建议 1: 严格构建波动方程可微逆散射层剥离算子 (DIS Layer)
- **消除绝对到时窗依赖**：摒弃脆弱的固有时域截取窗机制，引入一维瞬变流频域声学传递矩阵：
  $$\begin{bmatrix} H_{j+1} \\ Q_{j+1} \end{bmatrix} = \begin{bmatrix} \cos(\omega l_j / a) & -i Z_c \sin(\omega l_j / a) \\ -i Y_c \sin(\omega l_j / a) & \cos(\omega l_j / a) \end{bmatrix} \begin{bmatrix} H_j \\ Q_j - Y_{b,j} H_j \end{bmatrix}$$
- **层剥离解混前向流**：严格沿井筒由跟部到趾端（$x_1 \to x_{N_c}$）实现端到端可微解混：每一级提取物理反射率 $\Gamma_j$ 与支路导纳 $Y_{b,j}$ 后，立即在波动场中扣除其反射脉冲与二次透射损耗，消除多径混响，恢复纯净入射场向下级传递。以此彻底打破均摊效应，实现密集多簇 $R^2 > 0.75$。

### 建议 2: 补充裂缝亚米级定位偏差与起裂分类输出头 (Detection & Classification Head)
- **增加双重物理输出头**：
  1. 裂缝起裂存在性概率 $\hat{e}_j = \sigma(z_{exist, j}) \in [0, 1]$（识别未起裂或砂堵死簇）；
  2. 空间位置微调偏差 $\Delta x_j \in [-20, 20]\,\mathrm{m}$，使估计位置 $\hat{x}_j = x_{design, j} + \Delta x_j$ 能够吸收 $\pm 1\%$ 声速摄动带来的时延偏移；
- **完善评估指标库**：在 `src/metrics.py` 中正式实现基于 $\pm 10\,\mathrm{m}$ 空间容差匹配的 Precision, Recall 与 F1-score 计算函数，补齐 Phase 3 验收闭环。

### 建议 3: 标准化两阶鲁棒性自动化评估流水线 (Robustness Benchmark Pipeline)
- 新建专门的自动化鲁棒性审计评估脚本 `PaperC_CJNO_Wellbore_Inversion/experiments/evaluate_robustness.py`；
- 将 30dB, 20dB, 10dB 白噪声/粉红噪声，以及 $\pm 1\%$ 声速摄动封装为标准一键测试套件，自动生成符合 Nature/中科院2区标准的横向对标柱状图、噪声衰减折线图与雷达图。
